# PPT Toolbox 1.31.20 Windows

本次更新适用于Windows x64，包含标准版与精修版逐元素标注、标准制作流程兼容修复、原生对象工具和逐步新手教程。随包版本页、安装说明及更新记录同步到本次发行。Mac继续使用独立1.30.3测试版。

## 标准与精修逐元素标注

新项目按原生结构、图片素材、图标图形、基础样式和风险检查分类，每个源单元分别标注。位置图沿用极速版的编号和框选样式，JSON与Markdown逐项给出制作路线、编辑能力和必要备注，项目页可按编号对照。

制作Agent结合参考图、实际PPT和Office图判断修正。标准版沿用1.30.4的制作顺序与风险验收，精修版保持更细的字体、局部和代表性编辑检查。标注不增加一套验收流程，已有项目继续使用冻结设置和原标注。

## 制作流程与原生工具

修复标准与精修在早期小样、整页冻结时，完整制作设置中的workflow_profile被自身场景校验拒绝的问题。场景、页面和区域共用兼容定义，继续核对档位、所属流程与冻结哈希。恢复提示区分查询、已接受提交及结果未知，避免重复执行已经接受的制作。

原生图形内的文字进入适用的原文、字体和编辑检查。对齐分布、表格内容与格式、渐变阴影及文字底色组件的工具与说明随包提供。原生结构、图片保真和内部编辑按当前对象要求执行。

极速版首版优先提交默认开启。Agent完成全部页面并查看当前Office左右图，确认内容齐全可见后交付首版，位置和装饰细节按后续反馈修改。已记住关闭的选择继续生效，已签发编号的规则保持。

## 教程、接入与切档

新手教程按Agent接入、项目目录、制作准备、参考案例和辅助入口逐步聚焦。关键操作可单独跳过，结束页保留待处理项并支持重试。下次不再提示的选择保存在管理数据中，顶部仍可重看教程。

修复制作档位切换时草稿设置相互混入的问题，预览、保存与复制按有效档位生成兼容要求。通用接入说明支持当前MCP或本机受管CLI，连接记录与实际客户端验证分别显示。

## 安装、更新与验证

运行本页的完整Setup，升级沿用原程序位置、管理数据、项目目录和授权。有活动任务或写入锁时等待，更新清单继续使用既有可信密钥签名及SHA-256校验。安装器没有Microsoft Authenticode证书，Windows可能提示未知发布者。

本版从已验证的1.31.19程序包同步发行文档和版本元数据，制作实现、桌面宿主及锁定运行时保持。1.31.19的冻结源有201个去重用例最终通过，已安装代码分别生成标准、精修各47项标注。本次另核对1.31.20的版本、包内清单、正式安装和连接身份。标注、工程和安装检查不代替每份PPT实际制作时的Office及编辑验收。

本次不替换Mac附件。Apple Silicon仍使用[1.30.3独立测试版](https://github.com/sj18259360196-source/PPTToolbox/releases/tag/macos-trial-v1.30.3-20261025)，临时签名、未公证及手动更新范围保持，Intel安装包尚未发布。

公开仓库提供安装包、发行说明、更新校验文件和必要的第三方许可与对应源码。完整应用源码在私有仓库维护，GitHub自动生成的Source code归档对应历史公开源码，不能用于构建本版程序。
