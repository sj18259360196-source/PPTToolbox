# 图表、数据与OOXML修正

v1.3.0已有对应的可执行任务级入口，优先查看[直接操作](direct-operations.md)，本文件保留底层做法与历史条件。
## 图表编辑能力

E09/E10/E11/E18使用原生图表和嵌入工作簿；E07/E14/E16等采用独立路径或点线。两类都含可编辑对象，但能力不同。图表外围轴和图例若独立创建，即使曲线带工作簿，修改量程后仍可能需要手动同步。

原生表格的可编辑单元格也不等于其数值已经验算。没有执行有效计算的验证器不能给出计算正确的结论。

## 数据优先级

原始数据文件优先；截图可见表格值逐项转录；曲线未标注点只能估读。将准确转录和估读分别记录。没有数据时，先满足视觉编辑需求，不为了建Chart编造真实时间序列。

使用估读值建立Chart需在备注、数据说明与素材账本同时标注。保留坐标轴业务含义，不改横轴值补偿像素偏差。

## COM调用流程

`Shapes.AddChart2`建立图表，随后按当前Office实际对象模型设置系列。访问ChartData.Workbook前调用ChartData.Activate。工作簿数据、系列引用、轴范围和图例一起检查。Excel对象可能另起窗口；只关闭任务拥有的工作簿，不无条件退出Excel应用。[D07/D08]

COM创建失败时先做最小样例、检查Office状态和权限。可用python-pptx建立Chart及嵌入工作簿，再由Office验证。仅在关系结构明确时手工注入图表OOXML。不要把AddChart2失败降级成截图而不说明。

## 缓存一致性

图表缓存与工作簿引用需要一致。E11曾因浮点序列化差异而校验失败，按工作表XML中的原始数字字符串更新缓存才通过。

正确次序是完成Office保存→核对缓存及工作簿→有必要时最小修复→只读重开渲染→重新检查哈希。再次保存可能改变数值精度，不能沿用旧检查。

包内inspect_pptx仅检查传统Chart中单行或单列A1引用的基本缓存一致性，数值容差1e-12；不处理全部公式、外部工作簿、多级分类、新版ChartEx或数据真伪。遇到未支持项输出blocked，不修改文件。

## OOXML最小修改原则

在副本上解包，记录原哈希，按稳定ID找到目标，改变最小节点集合。不要清空整个spPr或删除所有p:style来粗暴修效果。若清除主题样式，先确认所需字体、线条和填充已经显式保存。

普通形状属性顺序中，xfrm与几何应在填充之前，线条和效果位于后面。以下只是局部示意，不能覆盖其他合法节点。

```xml
<p:spPr>
  <a:xfrm/>
  <a:custGeom/>
  <a:gradFill/>
  <a:ln/>
  <a:effectLst/>
</p:spPr>
```

E10/E12/E19/E21有填充节点位置错误的实例。包内渐变函数按几何节点定位，不固定写死第几个子节点。新增自由形状同样清理不需要的主题效果，避免只修普通形状入口。

## 常用OOXML位置

| 项目 | 节点 | 风险 |
|---|---|---|
| 普通文字边距、换行 | a:bodyPr | 单位混用、破坏原有布局 |
| 东亚/西文/复杂文字字体 | a:ea / a:latin / a:cs | 字段存在仍可能回退 |
| 固定文案艺术字 | a:prstTxWarp | 可以改字但可能被边界拉伸 |
| 原生自由轮廓 | a:custGeom/a:pathLst | 路径坐标、孔洞、闭合与边界 |
| 多色渐变 | a:gradFill/a:gsLst/a:lin | 色标、透明度、节点顺序 |
| 线条两端 | a:headEnd / a:tailEnd | 与起止端含义要核对 |
| 外阴影 | a:effectLst/a:outerShdw | 主题阴影与自定义效果重叠 |
| 图表与工作簿 | c:chart、c:externalData、rels | ID、路径、内容类型、缓存 |

XML能解析只说明语法可读。自定义OOXML补丁仍需结构回读、Office实际渲染和内容核对。包内不宣称提供完整ECMA-376验证。
