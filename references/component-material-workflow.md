# 分层分区与素材制作

当前制作偏好及版本以 [制作设置](production-settings.md) 和当前任务 production_settings 为准。

先查看整页，在现有 page_plan 中确定背景、层级和主要组件。每个组件在 element_scope 中记录 content_type、required_edit、material_route 和 text_ownership。已有的区域任务继续执行，无需另建评分任务或逐步审批。

新建参考图项目同时引用原始要求文件，在 material_contract 与各素材的 material_requirement 中记录来源、背景与独立编辑条件，字段见[插画要求与素材验收](material-quality.md)。保留原文和构图不等于要求保留截图字节。独立素材先检查主体与多底色边缘，再回装；切换生成或原生方法后重新核对保真度。

## 选择制作方法

| 组件 | 默认方法 | 需要核对的内容 |
| --- | --- | --- |
| 正文、可匹配的标题 | 原生文字 | 原文、字号、换行和位置 |
| 复杂装饰标题 | 按插画模式生成或原生绘制 | 准确原文、逐字结果、清晰度和可移动性 |
| 照片 | 按明确保真要求保留原照或参考生成 | 身份约束、内容准确、实际边界与来源 |
| 复杂插画 | 按插画模式生成或原生绘制 | 主体身份、数量、姿态、轮廓和内部文字 |
| 简单图标 simple_icon | 两种模式都原生绘制 | 曲线、孔洞、遮挡和颜色 |
| 几何图形 | Office 图形组合或布尔操作 | 结构、对齐和可编辑关系 |
| 准确 Logo 与已有素材 | Logo 保留身份要求，已有素材按来源资格与编辑需求选路 | 身份、比例和透明边缘 |

图片需验证整体移动、缩放和替换。可编辑绘制优先或用户指定内部编辑时，制作真实原生路径并核对内部部件。图片生成优先时，符合保真及编辑要求的插画、装饰标题和照片可用 content_category 直接申请参考生图，无需先试画或编造相似度。75% 只用于读取旧 low_similarity 记录。

先辨认真实色块和截图噪声。保留决定识别与质感的颜色、渐变和纹理；不要将压缩产生的色阶逐块堆成图形。钢笔与选区工具只服务已经选择的原生路线，每个部件保持闭合和连贯。无法稳定还原复杂边缘时重新选择方法，质量要求不变。

## 标题与素材内部文字

页面添加的文字用 page 归属。装饰标题用 decorative_title 和 asset_title，至少在 embedded_text 中声明一项准确可读原文并标为 readable。其他确实看不清的内容使用空 text 并标为 unreadable，不能猜写。

照片和插画内部文字用 embedded 归属。原照保留时文字随源像素保留；照片或插画采用参考生成时，其原有文字保留在生成素材内并检查实际输出。不要擦掉照片文字再覆盖原生文本。源照片依靠像素、哈希和裁切保留检查，内部文字无需逐字编辑。

source_review 会要求查看生成图片，并提交 material_text_checks。每行填写当前 object_id、asset_sha256 和实际读到的 observed_text 数组，顺序与 readable 原文相同。文字、标点或空格不一致时填写 needs_changes 或 blocked。模板中的空数组不能直接通过，元数据一致也不代表图片中的字已正确。

## 多素材合图

同页风格相容的小素材可以放进一条 request_asset 的 request.items，每次包含 1 至 8 项，一项也可用于局部补做。每项保存独立 ID、用途与 generation_decision；启用范围合同时填写 scope_unit_ids，按最终放置尺寸补充 min_subject_pixels。总请求将 multi_icon_sheet 和 transparent 设为 true。request_assets 是多任务提交，不能等同一次生图。

只合并能保持足够有效像素、完整轮廓和透明间隔的素材。不要让大小悬殊的主体挤在一起，也不要把不同标题串在一起。工具上限限制请求数量，实际数量还要根据画布与素材细节判断。

结果保存 sheet_sha256，每项记录实际像素 crop、viewed_files 和 accepted 或 retry。crop 使用 x、y、宽、高，不能猜网格坐标。控制器检查哈希、透明通道、裁切范围、重叠与主体像素，再保存原合图和独立 PNG。accepted 只表示本次裁切选用，最终视觉检查仍待执行。后续任务只包含 retry 项，已接受素材保持原样。

generation-prepare 生成同一份交接材料。generation-ingest 的 --crops 接收 sheet_sha256 和 items，正式提交时才写入受管素材。宿主不可用时如实保留待处理状态，不能伪造生图记录。

## 检查与返修

新工作流要求全页和重点局部左右对比。每页首次正式全页校验必看叠图，后续用于精确定位、指定区域或频繁检查设置，必看范围以当前任务清单为准。先检查大构图，再逐项检查标题、人物和小配角，避免只打磨最大的插画。未查看的组件不能通过，也不能用整页平均分代替。

路径复杂度、透明边界与有效像素仅提供诊断。检查副本中的素材移动、缩放与替换，并保存重开。实际 Office 渲染、可编辑检查、生成调用与单元测试分别记录。发现问题只返修相关组件；输入与对比图未变化的已通过观察，才可以按原有证据复用规则保留。

旧项目保留已保存的制作与检查策略。升级不补造原文、分类、叠加观察或验收记录。
