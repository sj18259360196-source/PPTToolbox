# 异形图形案例的工具化方法

这份说明依据 2026 年 10 月 9 日异型图形练习板的实际脚本、受管调用日志、Office 收据和局部对照整理。原项目位于 `C:/Work/PPTProjects\异型图形练习板-20261009`。证据索引见 `checks/shape-case-learning-20261009/case-evidence.json`。它记录制作动作和判断依据，不还原模型内部思维过程。

## 本次实际怎样绘图

参考页有五行、每行十项。Agent 在 1672 × 941 参考坐标中绘制，将画面分成页框和五个内容区。`production/common_shapes.py` 封装 path、ellipse、polygon、roundrect、group、circle_path、rounded_polygon 和 localize。前三份 shapes 脚本提供各行轮廓，assemble 读取当前任务包，将对象转成分区局部坐标后提交。图形主要由 Agent 手工指定节点与控制点，没有找到本案例调用自动描摹、曲线拟合器或 AI 生图的证据。

最终 scene 含 106 个文字对象、71 个路径、55 个 shape、3 条 line、10 个 group 和 2 张照片。122 个叶对象含渐变，其中包括编号底圆，因此不能称为 122 个独立插图。对象数量只说明表示结构。

| 实际方法 | 案例证据 | 可沉淀的能力与边界 |
|---|---|---|
| 少量三次贝塞尔段描述外形 | `shapes_rows12.py` 的 blob、云、液体形 | 用 M/L/C/Z 分开直边与曲边。曲线顺滑与相似度仍需实际看图 |
| 一份花瓣绕中心旋转 | 同文件 `_rotate` 和 `s16_eight_petal_flower` | 几何模板加旋转实例。修改根部可同步影响八瓣，渐变方向需另行决定 |
| 顶点沿邻边退让后接曲线 | `common_shapes.py` 的 `rounded_polygon` | 参数 r 实际是沿边退让距离，不能命名为精确圆弧半径。零长边缺少防护，不能原样升级为通用 API |
| 反向内环留孔 | 19 吊牌、32 信息卡、49 星形 | 外环和内环组成复合路径，孔洞不能用背景色盖住。多背景或移动后的验证仍需补充 |
| 分部件编组 | 蝴蝶结五件、沙漏四段 | 部件可独立改色，整体可移动。分组移动读回不证明取消组合、布尔运算或节点拖动 |
| 共用边界坐标 | `shape41_hourglass_bands` 的 781、803、824 水平边 | 共边应集中定义，避免分别修两侧造成缝隙。现有 `graphics` 命名边与面可承接 |
| 保留图层后调透明度 | 07 胶囊、24 两方一圆、25 双圆 | 保存前后次序、fill_alpha 与色标 alpha。叠色由各层合成，单张截图不能唯一反推原 alpha |
| 照片保留像素、框保留路径 | 28 山峰、29 海景 | 两张照片经 assets.crop 与 asset-add 入项目；mask 归一化，不能随页面坐标再次平移 |
| 修改后先试制再叠图 | regional_revision 的 probe → compare → adopt | 参考与候选对齐后，看顶点、切线、凹口、孔和文字。边缘重影是差异线索，不是自动通过条件 |

第 25 项虽标有相交形（布尔），脚本生成的是两个完整圆的透明叠加。第 26 项缺口和第 27 项三叶轮廓由路径直接画出。没有实际执行五种布尔命令的证据。参考图中的标题不能充当操作记录。

## 后续 Agent 可以照着做的制作顺序

1. 先看整页，确定布局、目标尺寸、关键形状与编辑粒度，在 page_plan.notes 简记取舍。识别原图重复编号等内容，不自动更正。
2. 为关键图形选择表达方式。外轮廓用闭合面；等宽线用线；重复部件用一个母形；孔用复合路径；透明重叠保留各层；操作训练保留操作数及结果分支。
3. 固定坐标合同。路径节点与控制点一同变换，shape/text 用 xywh。归一化 mask 保持 0 至 1；已经是 pt 的参数不重复缩放。
4. 先完成轮廓与前后关系，再调整渐变与透明度。单独核对渐变坐标框，避免修改控制点时填充效果意外改变。
5. 用有界试制验证关键差异。保持已对齐轮廓，只动出问题的部位。本案花瓣保留外端，延长并加宽根部，使其连接花心。
6. 实际查看 compare 给出的全页、局部并排与叠图。文字重影、整体平移、局部控制点偏差分别处理；每次仅采用当前试制关联的观察。
7. 将结构检查、外观对照、实际编辑和 scene 复现分开记录。某项未执行就保留未验证状态。

## 已经落地的经验与指令

经验 EXP-181 至 EXP-190 引用归档来源 S37，包含几何表达、圆角参数、放射实例、真实孔洞、共享边界、透明叠层、坐标转换、布尔操作证据、叠图修订和编辑验证边界。它们是本地证据复核后的方法记录，本轮没有重新执行 Office 验证。

`command-recipes.json` 新增五个指令模板，分别用于异形表达选择、透明与布尔分流、坐标回装、叠图修订、操作验证。模板会要求 Agent 发现当前合同，不能自动执行历史指令或提交视觉通过。

`examples/graphics/shape-radial-repeat.json` 和 `shape-alpha-overlap.json` 是新写的通用方法示例。前者演示围绕指定中心的仿射重复，后者演示两层带 alpha 的原生路径。它们没有复制本案例的具体图标，未进入素材收藏，也未通过 Office 外观验收。先 graphics_preview，再在当前授权项目 graphics_compile，检查返回对象后按当前任务回装。

## 下一步应补什么工具

下表保留设计时的输入与验证目标。五项能力现已接入受管流程，入口、参数和边界见 [异形工具](shape-tools.md)。历史案例没有执行这些新接口，不能把新样本证据写回案例历史。

| 优先级 | 扩展方向 | 输入和输出 | 应验证的结果 |
|---|---|---|---|
| P0 | 独立原生属性读回 | 候选路径、哈希、对象 ID；输出填充、渐变色标、alpha、分组、节点摘要与不支持项 | 无需修改文字即可取证，源哈希不变；样本应含组内路径和透明渐变 |
| P0 | 布尔操作学习试制 | 接入 rebuild_patch 的 native.topology，提供有序 operands、primary、action；每种操作产生独立副本与 scene 差异 | 两个圆相交仅保留透镜；差集次序可区分；片段数与并集关系检查；范围外对象不变 |
| P1 | 异形参数构建器 | 顶点、corner_inset 或明确圆弧半径、母形、旋转中心、次数；输出当前 graphics-recipe | 重复点、零长边、凹角、自交、极短边有明确拒绝或降级；保留少量可编辑节点 |
| P1 | 轮廓定量辅助 | 参考与候选同尺度局部、显式对象掩膜、排除区域；输出叠图、偏差分布与未匹配区域 | 分开位置误差和轮廓误差；抗锯齿与邻近文字不能决定图形通过；不输出整页验收分 |
| P1 | 自由形状节点编辑读回 | 指定节点及邻接控制点、受限位移、输入哈希；独立副本保存重开读回 | 节点坐标、路径数、孔洞数、组内归属及保护对象可核对；新 Office 渲染仍需看图 |

native.topology 的当前实现已支持 union、combine、intersect、subtract、fragment。限制包括顶层、未旋转、连续层序、闭合且无文字的纯色实心操作数，不能把本案含渐变与透明度的现成图组直接送入。应在新试制中明确建立合适操作数；不得为了演示擅自去掉原对象材质。

不必重复开发放射复制、共享边、局部试制和叠图。graphics 的 affine_repeat、edges/faces 以及现有 probe/compare/adopt 已能承接。真正缺口集中在更便捷的参数输入和与训练目标一致的操作证据。

原案例分析阶段只修改了源码经验、指令、示例与能力设计。后续工具验证使用独立合成样本，未修改原 PPT、登记用户验收或收藏自绘素材。发行和安装状态以对应版本记录为准。
