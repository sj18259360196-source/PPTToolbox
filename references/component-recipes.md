# 常见组件制作做法

## 按长度生成虚线

普通虚线可直接使用线条或路径的 `style.dash="dash"`。需要保留指定段长和间隔时，使用 `dashed_line` 组件，避免逐段手写坐标。

```json
{
  "id": "separator",
  "recipe": "dashed_line",
  "bbox": [74, 370.5, 874, 1],
  "params": {"dash_length": 4, "gap_length": 2, "axis": "horizontal"},
  "style": {"line": "FF9CB3", "line_width_pt": 0.6, "line_cap": "butt"}
}
```

段长和间隔使用 `bbox` 的逻辑单位，线宽仍使用 pt。横线沿外框的水平中线绘制，竖线设置 `axis="vertical"`，沿垂直中线绘制。末段在外框边缘截断，每次最多生成 512 段。组件输出一个含多段的原生开放路径，可整体移动和改色；修改段长或间隔需要重新编译。它不具备连接线的节点附着行为。

该规格先交给现有组件编译入口，再将输出放入场景，不能直接作为场景对象。Office 渲染和视觉对照仍需单独验证。

v1.3.0已有对应的可执行任务级入口，优先查看[直接操作](direct-operations.md)，本文件保留底层做法与历史条件。
以下以E01—E22的操作与反馈为基础，组织为可执行组件方案。具体坐标、颜色和字体都需重新测量。补充的原生命令见原生操作手册。

## 1. 信息卡片与编号底板

测外框、圆角、文字区域和重复间隔。先创建原生底形，再创建标题与正文；编号文字独立于底板。渐变先初始化再设色标，随后查主题效果。重复卡片用共同参数，不把本来不同宽的面板强行等宽。

检查卡片边界、文字基线、内部留白与渐变方向。不要用几百窄条无条件模拟一个普通渐变；确需多条结构时组合并记录维护代价。来源E02/E10/E14。

## 2. 平底半圆指标

组件由圆盘、平底半圆路径、数值和说明组成。先描上弧、两侧肩部和底边，构建闭合路径，再填渐变和加数值；三个重复指标先只做一个。

不能用圆角胶囊替代平底半圆。路径改变后先查Z-order，避免新底板盖住旧说明。必要时直接替换原对象几何而保持原层级。局部看轮廓后回到全页看视觉重量。来源E21。

## 3. 带图标与数值的圆形节点

将底圆、图标、主标签、数值、括号说明拆开，按原图分别设置字重。高光和暗部是可选独立形状，不得让整个节点统一套大号粗体。最后组合，标题与导语可留在组外。

图标白底若盖住连接线，检查素材背景及层级。圆形裁切解决矩形背景，不会让位图内部可编辑。用户要求原生图标时，用曲线和基本形状重绘并检查组内无图片填充。来源E17/E19。

## 4. 关系箭头与反馈回路

先列关系表，再测路径。需要节点拖动后保持附着时用连接线并设置两端连接；要求特殊宽箭头轮廓时用自由路径，说明手动维护。双向连线分别设置两端箭头，不以一条带末端箭头的线替代。

反馈回路先确定转角和控制点，不把连接线自动重路由用于所有精确路径。节点数组保持二维，线段用auto节点，显式三次曲线用corner节点并提供两控制点与终点。来源E12/E14/E17/E19。

## 5. 分区环带与三角关系图

环带根据参考拆成扇区。每扇区沿外弧正向、内弧反向构成闭合轮廓；各区分别着色，中心圆和节点独立。多层同心圆不能自动替代有分区变化的环带。

三角关系图先定顶点、可见边界与图标压住的区域；检查边线在图标外缘是否连续。只有被原图遮挡的线段才允许不可见。来源E17/E19。

## 6. 原生表格

创建行列→写单元格→设字体、内边距、段前段后→设列宽行高→检查实际渲染。行高压不下去时检查内容高度，不反复只写Height。

优先修单元格边框。外加水平/竖直线是局部补救；改变行列尺寸时须同步，必须说明。合并单元格和边框需要单独小样。来源E19/E21/E22。

## 7. 原生数据图表

确认原始数据是否存在以及是否需要联动。分类轴用类别数据；有数值间距意义的横轴选XY散点。设系列、坐标范围、标签、图例和绘图区。关闭或重设与原图不一致的默认标题。

不要改业务数值来补视觉偏差。截图估读数据写来源，禁止据此做统计结论。外围独立网格与图例虽然便于匹配，但不是全联动图表。来源E09/E10/E11/E18。

## 8. 截图轨迹与散点

只在目标绘图区内按颜色筛选，剔除网格、文字和图例。折线逐列测可见位置；散点按连通区域提中心。交叉、抗锯齿、遮挡与重叠会带来漏点和失真。

提取坐标用于显示重建，不能等同于原始采样数据。不要附加平滑以便省节点，除非已核对原走势。路径和点群按图表组合，轴和标签可独立编辑。来源E07/E14/E19。

## 9. 公式

少量固定公式可拆成文本、分数线、上下标并组合，保留每个符号和单位。文本组合公式不等于Office公式对象。长分母改写后需要调分数线；复杂公式应使用当前宿主实际支持的原生公式工作流并单独测试。

检查完整字符串的字符索引，避免下标落到错误字母。不得将公式截图冒充可编辑公式。来源E14/E15。

## 10. 照片和独立标签

图片仅覆盖照片区域，标签卡、说明和箭头独立。原照片含旧标签时只在允许范围内移除；可见语义信息另行保留。修补背景不能称为恢复真实被遮挡内容。

检查裁切边缘残字、漏高光、色块、照片断层和邻近卡片边。人物肖像、校徽和真实标志优先原始文件，不用生成替代身份或品牌。来源E04/E08/E10。

## 11. 标题纹理与光带

先寻找完整无字素材。窄条放大导致条纹时，优先更换更完整的来源或按已见结构重建，不反复沿一个方向拉长。背景颜色采样先排除文字。

SVG列状纹理相邻列重叠在E22有效，但它是局部实现，不能全局套同一个像素重叠量。来源E06/E13/E22。

## 12. 监控界面与仪表卡

窗口外框、导航、输入框、按钮、数值和趋势线分别建立原生对象；真正的复杂软件截图可作为局部图片，但不能吞入需要频繁修改的界面字段。

柱体和数值独立制作时，编辑说明必须注明不联动。按需要选原生Chart，避免交付后发现修改标签不改柱高。来源E05/E06/E11。

## 13. 异形底板、开孔与图片蒙版

遇到斜切卡片、缺口、月牙、圆环、拱形、弧形窗口和不规则照片框时，不要退回“用圆角矩形近似”。先读`shape-construction.md`，按预设形状→组合→布尔→自由路径→图片填充执行。

典型做法：

- 圆环：外圆减内圆。
- 带尾巴的标签：圆角矩形与三角形Union。
- 月牙：大圆Subtract偏移小圆。
- 不规则照片：自由路径作为图片填充形状。
- 分区环带：圆环Fragment后保留各片，或直接分别构建扇区路径。
- 凹口卡片：主卡片Subtract圆/矩形。

布尔之后重新检查对象名称、层级、填充和文字。Subtract对PrimaryShape顺序敏感。复杂对象的路线按[统一素材决策](asset-policy.md)选择；不把两轮失败设为生成资格，也不继续堆明显失真的近似小形状。

## 14. 复杂局部视觉素材

全息设备、发光图标、玻璃质感等插图先绘制，再按[素材规则](asset-policy.md)由 Agent 判断相似度。低于 75% 可转入透明背景生图，用户明确要求优先。容器、标签和关系线保留为原生对象。素材文件只覆盖自身轮廓，不吞入标题、数据、箭头或卡片边框。PNG 生图与 SVG 编写、描摹分开。

截图裁不干净时主动进入生成任务，不要等待用户再次提醒。生成后必须做Alpha检查、真实底色预览和局部左右对照。生成素材只能解决视觉主体，不得替代真实Logo、正文、科研数字或图表标签。
