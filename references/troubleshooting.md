# 按症状排错

先判断失败在输入、工具启动、构建、渲染、检查或日志哪一层，再找对象与属性。表中是来源里的局部证据及工程归纳，不保证所有同症状都同因。每次修复后必须回到参考图与Office结果。

| 编号 | 症状 | 优先检查与动作 | 验证与边界 | 来源 |
|---|---|---|---|---|
| T01 | Python缺win32com/OpenCV | 检查实际解释器，选择已有环境或PowerShell COM | 不假定所有脚本用同一个Python；不自动安装 | E03/E04/E06 |
| T02 | 固定pwsh路径不存在 | 查询PATH与宿主返回的真实路径 | 子进程也要测试；不硬编码用户名目录 | E06/E19 |
| T03 | Node模块导入失败 | 文件路径与ESM file URL分开，核对运行时变量 | 环境失败不直接说明PPT损坏 | E12/E13/E16 |
| T04 | COM导出失败 | 目录、完整Windows路径、权限、实际错误 | 反斜杠在部分记录有效，不是唯一原因 | E05/E13/E15 |
| T05 | 居中文字向左跑 | 读实际Width/Height，设置文字后恢复几何 | 再查可见边界，不能只加空格 | E02/E09/E13/E17 |
| T06 | TextFrame2.Characters调用失败 | 当前动态绑定对带参数访问的处理 | 单对象尝试TextFrame接口并重渲 | E04 |
| T07 | 多行文字重叠 | 换行符、LineRuleWithin和SpaceWithin | 先模式后数值，不靠增高框掩盖 | E15 |
| T08 | 中英文粗细不同 | NameAscii/NameFarEast/NameOther或a:ea | 同一个Font.Name不证明全部字形来源 | E06/E18/E21 |
| T09 | 文字过粗、负字距粘连 | 撤回描边/压缩，重新测字体字重和行宽 | 保留撤回记录 | E02/E06/E22 |
| T10 | 续行缩进重复 | 坐标已经含缩进时又加行首空格 | 只移除布局空格，保留有意义空格 | E22 |
| T11 | 下标范围错误 | 原始字符串与字符索引 | 局部放大核对完整公式 | E14 |
| T12 | 旋转文字被误报 | 旋转后的字形边界、组合变换 | 普通宽高规则不适用时标待查 | E05/E07/E10 |
| T13 | 渐变变白或颜色被覆盖 | 初始化与设色顺序 | 先调用TwoColorGradient，再设两端色 | E02/E09 |
| T14 | 渐变消失或变深 | a:gradFill在spPr内的合法顺序 | 不写死全文件统一索引 | E10/E12/E19/E21 |
| T15 | 多余默认阴影 | 主题effectRef与显式效果 | 全部创建入口一致处理 | E10/E19 |
| T16 | 图标外伸出长线 | 曲线节点数组维数及实际path XML | 单节点数组也保留外层，测单段和多段 | E17 |
| T17 | 自由曲线鼓出 | 节点编辑类型、控制点、闭合边 | 修一个组件后再批量 | E13/E14 |
| T18 | 星形变五边形、水滴方向错 | 当前对象枚举和旋转 | 用具名枚举，不凭记忆猜整数 | E12/E14/E19 |
| T19 | 箭头缺一截 | 先识别双向关系，再查层级和裁切 | 同尺度看两端，不只检查对象存在 | E06/E19/E22 |
| T20 | 三角边线被图标盖住 | 图片带底色、裁切范围、层级 | 圆形裁切不等于矢量重绘 | E17 |
| T21 | 半圆变胶囊 | 轮廓类型、肩部、底边 | 先重建轮廓，后调渐变 | E21 |
| T22 | 生图棋盘格背景 | 实际模式、Alpha范围和像素 | 不能只看透明外观；必要时纯色抠图 | E01 |
| T23 | 图片出现方形色块 | 素材背景和目标底色 | 在实际底色上查边，不盲目羽化文字 | E02/E04/E08 |
| T24 | 插图出现重复旧字 | 遮罩是否覆盖抗锯齿笔画 | 仅修装饰区域，原文仍原生 | E14 |
| T25 | 纹理竖条、照片断层 | 裁片范围、单向拉伸、遮挡顺序 | 寻更完整素材，恢复接缝，不强行加模糊 | E06/E08/E11/E22 |
| T26 | 提取散点数量不稳定 | 颜色阈值、面积、连通、遮挡 | 识别点数不是原数据总点数 | E19 |
| T27 | 表格被撑高 | 字体最小高度、边距、行距、列宽 | 先内容再重设行高 | E21/E22 |
| T28 | 表格网格不显示 | 单元格边框与主题 | 优先修边框，附加线需说明同步维护 | E19 |
| T29 | Chart能看但校验失败 | 缓存、引用、工作簿和序列化 | 最后Office保存后核对，不把数值改成假数据 | E09/E11/E18 |
| T30 | 替换图片后COM报错 | 是否访问已删除对象 | 插入/恢复层级后放弃旧引用 | E03 |
| T31 | 重跑后对象重复 | 残留文稿、模板内容、重复追加 | 新输出从干净输入构建，不关闭无关文稿 | E12 |
| T32 | 改图标误删标题 | 粗名称前缀匹配 | 稳定ID精确选取，先列出目标 | E13 |
| T33 | 改层级后正文消失 | 遍历中集合变化 | 先收集对象，后操作 | E21 |
| T34 | 检查器找不到PNG | 渲染是否完成、输出路径、编码 | 记录原检查失败，替代检查独立命名 | E02/E03/E07/E18 |
| T35 | 扩展画布测试整体偏移 | Office改页尺寸已移动对象 | 保存原几何后按原值＋边距恢复 | E02/E15 |
| T36 | 画布差1EMU | 最后保存的实际尺寸、容差与计算 | 不为通过去悄悄改验收要求 | E05/E20/E21 |
| T37 | 对象数或文本数很大 | 空文本体、runs、组合前后口径 | 分开报叶对象、非空文字和单元格 | E06/E14/E19 |
| T38 | 预览修改没变化 | 进程是否完成、源文件哈希、旧PNG | 新版本目录，导出后核对哈希 | E16/E22 |
| T39 | 验证报告输出被拒 | 当前验证器真实目录/覆盖契约 | 不能扩展为所有工具通用限制 | E12/E13/E16 |
| T40 | 日志编码失败 | 构建/导出/JSON是否已完成 | 独立记录已完成步骤，不概括全失败/全通过 | E22 |
| T41 | 删除被策略拦截 | 执行权限和本任务文件清单 | 保留未清理状态，不更换工具绕过拒绝 | 多份 |
| T42 | 保留脚本却无法重跑 | 系统临时原图、旧页依赖、试验顺序 | 持久化素材，明确入口和采用版本 | E06/E12/E16/E22 |

## 排错输出

每次保存症状、对象、排查证据、改动、验证和状态。若现象与历史案例相似但原因不确定，写成候选原因，不直接给历史结论。对共享函数的修复增加回归用例；对单页专用参数只保存在当前项目配置。
