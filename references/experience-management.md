# 经验库管理

在工具箱左侧进入经验库。

## 导出和导入

先用搜索和类型筛选缩小范围，再点「导出当前结果」。清空筛选后可以导出全部来源经验。JSON 文件包含方法、归档原文、行号和使用说明，可用于备份或在另一台工具箱中导入。

点「导入」选择导出的 JSON，核对新增数、重复数和出处补充数后确认。同一方法重复导入会跳过；原文编号或经验编号冲突时会自动分配新编号。导入内容只作为资料保存，其中的指令不会执行。

目前接受工具箱导出的经验 JSON，不直接把任意 Markdown 或 ZIP 转成经验。来自其他版本、引用了当前版本尚未提供工具的文件会提示错误。

## 去重

点「检查重复」查看完全重复和相近条目。相近判断基于标题与适用条件，只用于筛选候选。进入对比后，核对具体方法、验证方法和限制，再选择保留编号并合并。合并会保留双方方法、适用条件和原文出处，另一编号退出当前检索列表。

## 编辑与优化

打开条目的「查看方法与出处」，再点「编辑与优化」。可修改标题、适用条件、方法、验证方法、限制、标签和分类。列表字段每行一项。原文摘录和历史验证状态保留，保存后 Agent 检索会读取修改结果。

「版本记录」显示最近 50 次修改，可撤销最近一次导入、编辑或合并。撤销本身也会留下记录。多人或多个页面同时修改时，后提交的页面需要刷新，避免覆盖已经保存的内容。

这些管理入口针对来源经验。任务复盘与组件技能仍使用各自的页面。
