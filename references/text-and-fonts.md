# 文字与字体专项

先读取项目当前生效的[制作设置](production-settings.md)。相近字体优先使用本机风格和字重接近的字体；精细匹配用参考中的相同文字比较标题与关键字形。两种模式都检查原文、重叠、溢出、换行、间距与对齐。具体对象的明确要求优先，下文的样张、艺术字和轮廓方法按需使用。

首稿展开前如果拿不准字号，可以使用 [代表文本校准](stage3-calibration-impact.md)，通过现有小样入口集中测量标题、正文和混排文字。同样式页面共享建议，已验证的相同样本可以复用；它不增加每页必做检查。

v1.3.0已有对应的可执行任务级入口，优先查看[直接操作](direct-operations.md)，本文件保留底层做法与历史条件。
## 已验证经验及边界

E02、E09、E13、E17出现过文本框异常缩窄，先完成文字格式再恢复宽高有效；这与当次COM设置顺序有关，不能假定所有环境都会发生。E04的局部字符访问在TextFrame2动态绑定中失败，改用TextFrame成功。遇到同类兼容问题时，可用局部小样验证替代接口。

E15多行文字重叠与SpaceWithin为零有关。设置行距模式，再赋数值，并明确换行符，随后以Office导出确认。E22用textPlain艺术字匹配固定字形边界，但未证明适合长篇频繁改写。

## 创建顺序

创建文本框→关闭不需要的自动适应→设置四边距→写入文字与换行→设置中西文字体→设置局部字符范围→段落与垂直对齐→重新写入几何→读取实际边界→渲染。

COM几何与Font.Size用pt。`NameAscii`、`NameFarEast`、`NameOther`分别检查；`TextFrame2.TextRange`与旧`TextFrame.TextRange`不是所有绑定中完全可互换。字符范围索引需要按当前COM一基索引核对。

段前、段后与行内间距分别设置，不能用空行凑位置。段落优先时，同一语义段落放在一个文本框中，用 paragraphs 和 runs 保留局部样式，截图自然换行不自动拆框。逐行优先时按参考行位建框并按段落分组，编辑说明写明改长句时需要逐行调整。两种模式都不跨栏、卡片或语义区域合并。

## 文字问题的排查顺序

| 症状 | 先检查 | 不应首先做 |
|---|---|---|
| 起点与末端一起偏移 | 框坐标、内边距、对齐、真实宽高 | 改全部字体 |
| 起点对、末端太长 | 中西文字体、字重、字号、间距 | 移整栏或删字 |
| 居中围绕左侧 | 框宽是否异常缩小 | 补多个空格 |
| 笔画过细 | 字体实际字重、字体回退 | 给所有文字描边 |
| 多行堆叠 | 行距模式、SpaceWithin、换行 | 增加形状高度掩盖 |
| 下标范围错 | 原字符串与字符索引 | 修改业务公式 |
| 旋转标签误报溢出 | 旋转后可见占位与坐标系 | 直接比较未旋转宽高 |
| 圆点变小、续行缩进过大 | 符号是否随字体变形，坐标和空格是否重复缩进 | 压缩整段 |

正常字体和合适框宽优先于缩字号；负字距和描边补字重只作可撤回局部试验，E02/E06/E22均记录过失败结果。

## 字体样张

选主标题、粗体栏目、普通正文、中英数字混排各一例。在当前Office中渲染候选字体，比较同一字或同一短句的笔画与边界，不只比较全行总宽。既有字体名称只是候选，不是原稿字体证据。字体字段存在不代表每个字形都由该字体绘制。

不分发字体文件，不从非官方来源下载所谓同款字体，不自动嵌入有许可限制的字体。换机后需要重开检查换行和字形。

## 艺术字与轮廓

复杂设计标题按[素材规则](asset-policy.md)和当前插画模式选路。图片生成优先且整体编辑满足要求时可参考生成；可编辑绘制优先时使用实际原生对象或路径。明确要求改字时保留原生文本，路径不能替代文本改字能力。图片标题保存准确原文并逐字检查实际输出，已选生成路线无需先测试本节的字体、艺术字或轮廓方案。

正常文本匹配无法接受时才测试 `a:prstTxWarp prst="textPlain"`，保持原字符串与正常字距。把内容固定与后续编辑限制写入对象备注。文字轮廓化要单列对象类型，不能把它计作可改字的文本框。

艺术字字号字段不一定等于可见高度。普通组合的非等比缩放也不能被假定为正确的字形缩放手段。E22测试过并放弃部分组合缩放和负字距方案。

## 内容校对

原图→转录清单与转录清单→PPT两道核对独立完成。严查小数、百分比、±、负号、单位、上下标、括号、引文符号、中英文缩写和续行。未知字符单列，不用OCR或语言模型猜测补齐。

`BoundWidth/BoundHeight`是文本边界证据的一部分。正常旋转、艺术字、多栏、表格单元格与复杂基线可能需要独立检查，不能因一项几何检查通过而称文字全部正确。
