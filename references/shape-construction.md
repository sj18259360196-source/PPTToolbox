# 异形构造、拼接、裁切与图片蒙版

v1.3.0已有对应的可执行任务级入口，优先查看[直接操作](direct-operations.md)，本文件保留底层做法与历史条件。
本手册解决一个高频失败：Agent只会圆角矩形、圆和箭头，遇到异形图标、环带、缺口、弧形面板或不规则照片边界就直接放弃。参考稿复刻不要求所有视觉对象都用一种方式实现；应按编辑需求和视觉复杂度选择表达方式。

## 一、按轮廓选择构造工具

整体路线服从[统一素材决策](asset-policy.md)。以下是可选工具，不是必须逐项失败的流程。

| 轮廓特征 | 适合的原生入口 |
|---|---|
| 预设形状接近，主要差别是圆角或肩部 | 预设形状与 `Adjustments` |
| 希望各个子件独立编辑 | 基本形状拼接、分组 |
| 开孔、缺口、环形、交集轮廓 | Union / Combine / Intersect / Subtract / Fragment |
| 平底半圆、环形扇区、特殊宽箭头 | `BuildFreeform` / `AddNodes` 自由路径 |
| 已有图片，只需改变可见窗口 | 原生形状或路径加图片填充 |

## 二、停止重复无效尝试

主体为复杂质感且允许局部图片时，可直接采用获准 PNG 生成或准确现有素材。已选择的同一种原生方案持续偏离参考，应切换方法，而非反复调整无关颜色。需要内部路径编辑时继续保留该硬要求，不能通过图片化隐去。

PNG 生图和 SVG 编写、描摹是不同能力；参见统一规则。图标外框、文字、数值和关系可以继续保持原生，与局部质感图片分别管理。

## 三、布尔运算怎么选

| 目标 | 常见操作 | 示例 |
|---|---|---|
| 把多个轮廓连成一个 | Union | 圆 + 矩形 → 圆头标签 |
| 保留重叠以外的组合轮廓/孔洞 | Combine | 两个重叠圆做镂空图标 |
| 只保留重叠部分 | Intersect | 图片/渐变只显示在某个异形区域 |
| 从主形状挖掉一块 | Subtract | 外圆 - 内圆 → 圆环；卡片 - 圆 → 缺口 |
| 切成多个可编辑片段 | Fragment | 环带、拼图、分区形状 |

Subtract的主形状和次形状顺序有语义，必须明确PrimaryShape。MergeShapes会替换原对象，操作后重新获取结果对象并命名，不继续使用旧引用。

### 常见复合轮廓

- **环形**：外圆减内圆；需要四象限时再用Fragment或分别构建四个扇区。
- **带三角尾的标签**：圆角矩形Union三角形。
- **内凹箭头**：箭头主体Subtract一个三角/圆。
- **拱门/平底半圆**：上半圆与矩形组合，或直接自由路径。
- **月牙/弯月**：大圆Subtract偏移的小圆。
- **不规则照片窗口**：用目标自由路径作为图片填充容器，不先裁成矩形再叠遮罩。

## 四、自由路径的拆法

先找最小外接框，再以局部坐标记录轮廓。路径命令仅使用已经验证的M/L/C/Z：

- `M x y` 起点
- `L x y` 直线
- `C c1x c1y c2x c2y x y` 三次贝塞尔
- `Z` 闭合

先画轮廓，不加光效。局部对照确认顶点、肩部、底边和凹口后再上色。路径有异常长线时先查节点数组维度和控制点，不靠遮罩掩盖。

## 五、异形图片蒙版

如果视觉主体是照片/复杂纹理，但参考图使用圆形、弧形、叶片、斜切或其他异形窗口：

1. 创建目标原生形状或自由路径。
2. 用`Fill.UserPicture()`将图片作为形状填充，而不是插入一张矩形图片。
3. 关闭不需要的轮廓线。
4. 调整形状自身尺寸和路径来匹配参考。
5. 在真实页面底色上检查边缘与抗锯齿。

包内`NativePpt.psm1`提供`Add-PptPictureFillShape`和`Set-PptPictureCrop`。复杂自由路径也可以先`Add-PptPath`，再调用`Set-PptShapePictureFill`。

这种方式保留外部轮廓可编辑，但图片内部仍是位图。交付说明要区分“可改蒙版轮廓”和“内部像素可编辑”。

## 六、异形操作的建议顺序

```text
识别参考轮廓
→ 判断是否需要内部逐点编辑
→ 预设形状/调整柄
→ 基本形状拼接
→ 布尔运算
→ 自由路径
→ 图片填充蒙版
→ SVG/透明PNG
→ PowerPoint导出
→ 局部左右对照
```

同一个对象最多让一种失败方案消耗两轮。已经证明轮廓方向错误时，不要继续调颜色和阴影。

## 七、原生函数入口

```powershell
Import-Module './scripts/NativePpt.psm1'

# 两个形状做减法：ring.outer - ring.inner
$result = Merge-PptShapes -Slide $slide -Id 'ring' -Names @('ring.outer','ring.inner') -Operation Subtract -PrimaryName 'ring.outer'

# 圆形/预设形状内填图片
$photo = Add-PptPictureFillShape -Slide $slide -Id 'avatar.mask' -Path './assets/avatar.png' `
  -Geometry Oval -Left 100 -Top 100 -Width 120 -Height 120

# 自由路径作为图片蒙版
$mask = Add-PptPath -Slide $slide -Id 'photo.mask' -Commands $commands -Fill 'FFFFFF' -Line ''
Set-PptShapePictureFill -Shape $mask -Path './assets/plant.png'
```

函数只是操作入口。MergeShapes和图片填充必须在当前Office做最小样例；包本身不声称已在所有Office版本实机验证。

## 八、审查

异形图至少检查：

- 轮廓是否属于正确几何类型，而不是“颜色差不多的错误形状”。
- 凹口、孔洞、内外圆是否存在。
- 图标底色是否遮住关系线。
- 组合/布尔后层级和文字是否被覆盖。
- 图片蒙版边缘是否有原背景色、白边或黑边。
- 局部左右对照是否使用同裁切框和同倍率。

历史复盘中，胶囊代替平底半圆、图标矩形底色盖住三角边线、双向箭头漏一端等都属于“结构错但整页缩小不容易发现”。因此异形对象必须做局部对照。
