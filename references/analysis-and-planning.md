# 分析、拆解与决策

## 资料口径

本模块的对象拆解、先几何后装饰、已知与未知分离，来自E01—E22。统一数据结构、阶段检查和优先级是本次工程整理，不代表22份历史任务均完整执行。具体出处见来源账本。

## 从整页建立可核对模型

先看参考图而非只读文件名。依次确认页面尺寸、信息分区、阅读路径、重复结构、关系图和特殊素材。不要先找模板，不重新组织内容。

先判断哪些区域决定整体效果、哪些内容必须完整、哪些对象的方法还不确定。根据视觉影响、编辑需求、风险和预计投入安排重点，无需计算固定分数。观察、转录、几何测量和素材选择可以交替进行，工具调用顺序由当前页面决定。

在已有 page_plan.notes 写简短的制作判断，各区 summary 写目标，local_review 标记必须仔细检查的重点区。regions 数组仍按背景到前景排列，它控制叠放顺序；制作优先级写在 notes 中。后续区域任务会携带这份判断，Agent 可按新观察在 source_notes 补充调整依据，不必重填整页分析表。

通常先完成布局、图标、形状、组件和背景，再收敛局部细节。高影响且方案不确定的对象可先试一个代表样例，简单对象直接制作；不要求每个区域先做小样。每轮看实际结果，重新排列未解决问题。

字体默认选风格、字重相近的可用字体，保留可编辑文本。内容完整、无重叠溢出、无异常换行、间距和对齐合理是必须完成的检查。用户明确要求原字体或特定字形时，再提升字形匹配的优先级。

| 信息 | 存什么 | 不允许的推断 |
|---|---|---|
| 可辨内容 | 原文、标点、数字、单位、下标 | 用科学常识改掉疑似笔误 |
| 可测几何 | 实际图片尺寸、边界、圆心、间距 | 把上页坐标当本页测量 |
| 外观近似 | 字体候选、字重、阴影、渐变 | 把候选字体说成原字体 |
| 缺失信息 | 遮挡背景、不可辨小字、原始数据 | 编造文本或测量数据 |
| 编辑需求 | 改字、改几何、改数据、替换图片 | 一律宣称全部可编辑 |

E05保留了参考图疑似重复的2#；E09区分表格照录值与曲线估读值；E16发现真实宽度1671与脚本1672不一致。这些例子说明转录、测量、推断必须分开。

## 对象选择决策

文字默认原生文本。规则几何默认预设形状；预设轮廓不符时用自由路径或合并形状。连线既要表达方向，又要按需求决定是否附着节点。结构化表格保留行列。照片和复杂纹理保留独立图片。复杂图标先明确用户是否要求内部矢量编辑。

| 要求 | 推荐实现 | 必须披露 |
|---|---|---|
| 日后频繁改句子 | 正常文本框/段落 | 替代字体造成的外观差异 |
| 固定文案、特殊字形 | 先找字体，再测试艺术字 | 字形变形后不宜大改内容 |
| 内容固定、只要求轮廓 | 获准后转文字路径 | 无法直接改字、搜索和提取受限 |
| 改数字后曲线更新 | Chart＋嵌入工作簿 | 数据源是否真实、估读或演示 |
| 只改曲线位置、颜色 | 自由路径＋独立轴标签 | 不支持数据联动 |
| 图标能移能换 | 独立图片 | 不支持内部逐路径修改 |
| 图标必须可拆改 | 原生路径或形状分组 | 核查孔洞、精度和节点数量 |

编辑颗粒度按内容单元决定。圆形节点拆成底形、图标、名称、数值、说明，再组合；文字不要和装饰永久合并。很多极细渐变条并不自动提高可用性。E07尚未充分分组，E14大量对象来自渐变条，均不能视为优点指标。

## 坐标和单位

本包scene明确 `width/height` 为逻辑设计坐标，`width_pt/height_pt` 为幻灯片物理点数。几何转换为 x_pt=x×width_pt/width；字体和线宽直接用pt，不再乘几何系数。

统一缩放默认要求逻辑画布比例等于物理比例。输入截图略有整数取整差时，可以定义逻辑设计高度为宽度÷目标比例，同时记录原图到逻辑画布的映射。所有裁切仍基于原图真实整数尺寸。

截图与目标比例明显不同时，选择等比留白、等比裁切或经用户接受的非等比映射，并记录。不能通过自动拉伸掩盖差异。`explicit_stretch`只是显式允许两个比例的技术开关，不代表推荐使用。

E19采用过横纵独立系数，E22采用统一系数；来源做法并不完全相同。本包默认统一比例，是为减少圆形和字形变形所作的新选择。

## scene字段与层级

每个对象必须含稳定ID、kind、editability、evidence。证据可用observed/measured/inferred/unknown；测试数据用synthetic。confidence只表达Agent判断强弱，不能伪装成概率校准结果。

文字既可 `text`，也可 `runs` 表达局部字重和上下标，不能两者同时设置。容器边界用 `[x,y,width,height]`；裁图与对照区域用 `[left,top,right,bottom]`，两者不能混用。

数组顺序代表从底到顶。连接线可出现在节点之前，在所有对象建立后再附着。组合children用同一全局逻辑坐标，构建器自动计算组合范围；不要又加父组偏移。

内置构建器禁止静默忽略字段。高级艺术字、复杂Chart布局、SmartArt、SVG导入和任意效果应通过页面专用适配器实现，标记实际支持范围。

## 决策记录模板

记录观察、对象ID、证据文件、候选方案、选定动作、理由、代价和复核方法。例如箭头缺一截时，先分辨原图是否双向，再查节点坐标、前后层级和裁切。确认因后建卡片覆盖后，仅调整相应层级并重新导出。

不输出冗长自言自语；需要的是其他模型可以检验和执行的决策摘要。
