# 花字与完整贴纸素材

用于参考图中的设计标题、照片贴纸、细长尖刺或复杂镂空。素材路线仍以 [asset-policy.md](asset-policy.md) 为准。本页补充贝壳封面的实际经验，不把单页有效的方法推广成所有对象都要生图。

## 先确定编辑深度

普通说明、数值、单位与信息关系继续原生。设计花字在用户允许不逐字编辑时，可作为独立透明 PNG；原文仍须逐字核对。声明标题是整张图片，能移动、缩放和替换，不能直接改其中一个字。若要求每行或每字独立移动，生成前按该粒度拆分。

已有干净原素材时直接采用。字体小样明显无法接近设计字，或粗蒙版会切断照片主体且已允许生成近似时，直接测试生成候选，不需凑够两次失败。照片中的真实标识、物种诊断细节、人物身份和科学证据不能因这个案例而默认近似。

## 先做最难的一个局部

选择实际标题或最复杂的轮廓作小样。生成提示包含参考图、准确文字、主体数量、姿态、方向、主色、完整边缘和透明底要求。白边按参考需要生成，主体与边框周围留出安全空间。要求完整尖端、孔洞和褶皱，不带邻近文字、背景残片或整页布局。

把结果放回真实页面再决定是否批量生成。单张素材好看不代表尺寸、间距与相邻对象适合。贝类纹理与姿态发生变化时记录为生成近似，不能声称找回原照片被遮挡的细节。

## 透明底需要实测

确认文件有 alpha 通道及透明像素，孔洞和主体间空隙也需检查。RGB 在 alpha 为 0 的位置可以保留灰色或其他颜色，素材预览中的灰边不一定会出现在成片中。先在实际背景和 PowerPoint 中回装检查，再决定是否重新生成。

反过来，有透明像素也不能证明边缘干净。检查白边连续性、半透明噪点、光晕、截断和近透明主体。本案例未建立通用 alpha 裁切阈值，不能把个别脚本参数推广为标准。

## 回装与保留

依据可见主体的范围放置图片，留意透明留白导致的缩小或位移。照片优先等比缩放；需要改变纵横比时检查形态是否被拉长或压扁。白边不得靠裁切牺牲尖端，阴影不能掩盖缺损。

每个需要独立操作的主体或组合保留为独立图片。保留生成原文件、提示词、实际工具来源和采用理由；舍弃版本记录原因。生成输出先复制到项目的持久素材目录。asset-add 后重新领取任务包，使用新 token 和素材路径，不能提交旧模板。

用同一最终 PPTX 的 PowerPoint 导出制作全页及局部对照。核对花字内容、照片数量、轮廓完整性与实际透明效果；正文与形状在副本中编辑、保存重开。冻结素材重建一致只证明同环境复现，不代表原图保真，也不证明下一次重新生图会相同。

## 验收边界

分别记录本轮改善、仍有差异和整体是否通过。用户授权生成只确定制作路线，不自动构成对最终成片的认可。未完成的普通装饰或布局差异继续保留，不因主标题变好就批量填通过。来源与本次结果见 贝壳案例（本地验收记录未随包提供）。
