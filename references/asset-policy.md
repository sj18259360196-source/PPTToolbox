# 素材选择的唯一决策规则

本文件是当前 Skill 素材选择的权威规则。主入口、素材手册和异形手册只引用此处，不另设相反的优先级。该决策继续沿用第一阶段修复。v1.2新增素材任务交接，尚未增加真实宿主生图API适配器。

## 按对象选择，不强制遍历一条阶梯

先检查用户原始素材和当前项目经核对的资产。插图与图标默认先由 Agent 使用 SVG 或原生对象绘制，再对照参考局部判断相似度。低于 75% 时可以使用 AI 生图；75% 及以上继续原生路线。用户明确要求直接生图时可跳过绘制，要求原生可编辑或禁止生图时遵从用户要求。真实标志、图表、文字和关系线继续按原有编辑要求处理。照片、纹理、连续色调画作以及符合本节条件的生成插图都要提交 raster_content、raster_reason 和逐项 asset_decisions。

| 对象条件 | 应采用的动作 | 采用前检查 |
|---|---|---|
| 正文、数字、单位、表格、图表轴标签、信息关系 | 原生文本、表格、形状或数据图表 | 内容和方向正确，编辑方式满足要求 |
| 真实校徽、品牌标识 | 依据准确来源重建原生路径和文字；保持识别轮廓 | 不用近似生成改变标识，不以截图代替重绘 |
| 人物照片、纹理、连续色调画作 | 用户原始资产或对应准确来源；需要裁切时声明图片用途 | 不改变身份；检查邻近文字、底色、透明边缘及实际清晰度 |
| 用户允许不逐字编辑的设计花字 | 可直接测试独立标题 PNG，保留准确原文与设计风格 | 逐字核对，声明图片只能整体移动、缩放、替换；普通正文继续原生 |
| 粗蒙版会截断尖刺、褶皱或完整轮廓，且用户允许主体近似 | 生成完整独立透明素材，按参考需要带白边 | 数量、姿态、孔洞、尖端与白边连续性；生成细节不能冒充原照片 |
| 轮廓简单或可参数化的组件 | 预设形状与调整柄、拼接、布尔或自由路径，选择适合的一项 | 先查轮廓和连接，再查光效 |
| 复杂发光图标、玻璃、全息或设备透视 | 先绘制，由 Agent 判断局部相似度；低于 75% 可将参考局部交给宿主 AI 生成透明 PNG，用户明确要求优先 | 保存绘制稿、分数、理由，核对数量、姿态、方向、主色、透明边缘与回装效果 |
| 有匹配的官方或许可明确的单项资源 | 与当前参考吻合时直接采用，不要求先生成 | 来源、使用条件、轮廓与风格；不能仅凭语义相似替换 |
| 明确要求内部路径可编辑的复杂图标 | 原生拼接、布尔、自由路径或确含矢量路径的 SVG，并检查在 PPT 内的实际对象形式 | 不能用可移动 PNG 冒充内部路径可编辑 |

用户已经允许本任务的复杂局部生成，且对象满足表中条件时，不要反复等待用户再次授权同一个动作；但不得自行改用未经许可的新外部服务上传私有材料。工具未发现、未获授权、调用失败、产物不合格分别记录。

## 绘制后的相似度判断

75% 是制作 Agent 对单个插图的视觉判断阈值。需要看过参考局部和实际绘制稿，记录差异，不冒充软件测量或整页验收分数。低于阈值可以直接切换，无需重复失败两轮。内部逐路径编辑是用户硬要求时继续修订原生绘制。生成图片可以单独移动、缩放、裁剪和替换，其内部线条不因此变得可编辑。

request_asset 中加入 generation_decision。下面的分数仅示范字段，实际使用必须填写自己的判断。路径均相对于当前项目，文件必须存在。

```json
{
  "action": "request_asset",
  "request": {
    "id": "illustration-01",
    "purpose": "替换本项目已绘制但轮廓相似度不足的插图",
    "prompt": "参考提供的局部图生成独立透明背景素材，保持数量、姿态、颜色与风格，不带正文和连接线",
    "transparent": true,
    "allowed_approximation": true,
    "multi_icon_sheet": true,
    "generation_decision": {
      "basis": "low_similarity",
      "reference": "input/reference.png",
      "drawing": "assets/illustration-draft.svg",
      "similarity_pct": 72,
      "reason": "填写实际观察到的轮廓、比例或风格差异"
    }
  }
}
```

用户明确要求直接生图时 basis 填 user_request，在 reason 中记下要求，drawing 与 similarity_pct 可省略。宿主工具、参考上传权限及项目限制继续按 toolbox_material_policy 执行。

生图优先使用真实透明背景，多个图标之间留出透明空隙。可对同一 PNG 创建多个独立图片对象，分别填写 source_crop 像素裁剪框；也可先裁成单独文件。插入时用 source_kind=generated、raster_content=generated_illustration，保留原 generation_decision，并逐项填写 asset_decisions。图标使用 asset_role=icon，插图使用 decoration；普通文字和关系线单独保留。

## PNG 与 SVG 分开

PNG 生图使用实际可调用的图像工具；编写、描摹或矢量化 SVG 是另一种操作，不假设图像工具支持输出真正的 SVG。将 PNG 改后缀或嵌入 SVG 不会得到内部矢量路径。插入 PPT 后的 SVG 也必须检查对象形式。

## 给 Agent 的可选方法建议

背景的规则色块和渐变使用原生形状重绘。照片主体与底色粘连时，可考虑抠图或透明边缘清理。简单插画、图标使用组合形状或原生路径；已有干净的黑白语义蒙版可用项目内 icons_trace_fragment，再核对轮廓和孔洞。复杂纹理按图片用途规则处理，不必强行转成大量节点。

上述方法目前只加入制作建议，没有新增自动背景重绘、抠图或插画矢量化引擎。Agent 根据当前工具、已有授权、参考保真要求和投入选择，缺少入口时如实说明。采用生成或重绘后应核对主要轮廓、数量、方向、颜色、构图及回装效果；不能把近似细节当作原始素材。

## 每条路线都要回装检验

登记参考和产物 → 检查真实文件 → 必要的透明与边缘处理 → 放入目标页面 → PowerPoint 导出 → 对应局部左右对照 → 采用或修订。

局部图片可以承载复杂质感，但不烘焙本应保持原生的正文、数字、表格与连接关系。生成补全是合成近似，不能宣称找回被遮挡的原始照片细节。

## 图标与插画必须记录采用理由

当前任务提供 asset_decisions 字段和生成请求示例。需要检查残字、白色描边、模糊补丁、孔洞和实际轮廓。可重绘图标失真时先看对应局部对照，由 Agent 按本节阈值及用户要求决定继续绘制或转入生图；不能只因耗时就宣称低于阈值。

保留原插画可以避免重新生成改变构图和风格，这是选择依据而非保证效果的证据。未实际生成候选就不能宣称生成一定更差。可在同页对关键失败局部生成候选；不必全页所有图标重做，也不必为了测试接口替换真实Logo。

asset_decisions只是模型记录，不能证明工具调用。真正生成要有实际工具调用、真实产物和来源；不得把尚未查找入口写成无生图能力。

## 素材持久授权

读取 toolbox_material_policy 或 context.material_policy。联网搜图、宿主生图、上传必要参考局部默认允许，项目可以覆盖全局设置。允许值是用户保存的授权，不重复询问；用户当前明确限制优先。不开通新的付费服务，不扩大到未经许可的新服务或无关资料。宿主工具不可用时报告能力缺失。
