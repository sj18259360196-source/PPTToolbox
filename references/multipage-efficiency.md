# 多页制作与修订

任务返回 view_strategy，包含当前看图范围、图片哈希、像素尺寸和文件字节数。字节数只统计本地必看文件，不代表供应商请求大小或请求延迟。action=views 也可读取这些信息，不会替 Agent 记录看图。

项目运行路径显示整页主视觉、高清局部的要求查看次数及已提交观察次数，另列同哈希图片重复要求、重复领取和当前审查复用。要求查看按 task_id 去重；同任务多次 next 只增加最近调用中的重复领取计数。已提交观察来自通过提交校验的 Agent 回执，不代表独立观测到宿主打开图片，也不等于审查通过。制作任务未提交 viewed_files 时显示未提交观察，不推断 Agent 没有看图。

统计可从旧项目的任务包和观察记录恢复，不改写制作状态。缺失文件、当前必看图哈希改变或观察记录异常会标为统计不完整，并在项目顶部提示。最近工具调用耗时与供应商请求延迟分开显示，后者未知。工具箱不会监测或修改宿主会话文件，无法自动获知宿主到供应商之间的断流。恢复后通过现有 blocked 或 resume 打卡记录报错和当前任务，继续前先核查是否已有提交成功。

最近 24 个看图任务的本地必看文件累计达到 20 MiB 时提示考虑短对话续作，最近调用中重复领取达到 3 次时提示检查当前任务。这些是操作提醒，不是供应商限制，也不强制停止制作。历史统计最多缓存 30 秒，工作流修订和当前图片文件变化会提前刷新；统计只读元数据，不重新生成或打开整套图片供模型查看。

受管调用返回的 stage_context.visual_context 会带上观察器最近一次图片统计和提醒。快照可能晚于当前任务，以 observed_at 为准；pending 表示尚未采集，不能按零处理。该摘要不附图片或完整历史文件清单。

超过 1600 像素的大图在 page_plan 中提供布局概览。区域坐标继续使用 reference_size，不能沿用缩略图坐标。region_objects 和 asset_material 保留原始像素裁图。source_review 和最终视觉核对保留原始图；文字或细线被查看器缩小时，用 assets.crop source output --box left top right bottom 补看语义局部。跨区关系不清楚时可扩大范围，由 Agent 按问题选择，不限制补看次数。

整套 replace-scene 后，工具比较各页完整场景、画布和素材哈希。只有绑定完整且记录未变的 passed 原图观察可保留。文字、数值、样式、几何、连线、素材或画布变化都会触发重新核对。旧版缺少绑定的观察继续可读，但首次替换后需重新核对。复用记录保留原任务来源，不自动批准新渲染或编辑测试。

同页局部视觉观察也可保留，但要同时核对区域范围、覆盖对象、相交对象及顺序、整页关系对象、共享依赖和实际 Office 局部对照图。任一变化就重新审查。改动页仍需整页视觉核对；跨区连线或遮挡变化扩大检查范围。新的失败观察会阻止较旧的通过观察被复用。

对照图默认使用原始像素，避免将局部插值放大两倍。并排图、叠加图和差异图继续生成并校验。独立原图裁片和渲染裁片改为按需输出，可用 --include-source-crops 恢复；--region-scale 2 可显式放大。PNG 无损编码不改变解码像素，历史图与回执不重写。

重复 next 返回同一个未完成任务。同一上下文中已实际查看的同哈希图片无需重复打开；上下文丢失后需补看当前必要图片。对话变长时保存修改和发现，从项目 HANDOFF、status 和 next 接续，避免再次扫描历史图片目录。不要将缓存命中或重复任务当作视觉通过。

多页制作调用 rebuild_submit 时设置 return_next=true。CLI 使用 submit --return-next。直接处理返回的 task，只有没有返回任务、需要查询状态或处理失败时再调用 next。accepted_task 表明提交已完成，即使后续领取失败，也不能重放这次提交。工具按原有权限执行，未自动填写审查结论。

调用结果和 call.json 的 timings 分别记录授权检查、代码身份检查、未决调用检查及子进程等待。累计调用时长包含等待，不等于可节省的净计算时间。

validation_metrics 补充图片读取、哈希、解码、状态验证和下一步领取的次数与耗时。
同一次调用可复用相同内容的图片解码结果，每次使用仍重新读取并核对哈希。
各阶段可能相互包含，耗时不能简单相加。恢复状态与字段约束见 workflow-efficiency.md。

toolbox_project_inspect 接受明确的 project 路径。action=identity 返回 project_root、project_id 和 workbench_key。复盘接口也接受已登记路径和项目 ID，歧义或身份不一致时拒绝。

action=scene 对当前场景或已授权 scene 文件执行只读预检。changes 使用完整 object_id 和 set 字段，支持明确的几何、文字和样式修改。不会补造 evidence、静默删除悬空引用或改写原文。报告 valid 后仍须通过受管 patch 或 replace-scene 应用修改。

impact 按变化页说明对象、原区域计划是否可验证以及是否需要重新规划。
变化页须重新观察，返回预检通过不代表视觉验收通过。

移动或缩放对象后，只要对象身份集合、原区域计划和坐标映射仍可验证，且对象没有越出授权区域，即可保留局部修改合同。新增或删除对象、改变坐标系或跨区域修改需要重新规划。缺少原始计划时，使用明确的页级 revise 重新领取计划，不能修改 state 绕过。

工具仅对整页对象、主题、共享素材和 Office 对照图均一致的页面关联旧视觉观察。关联记录保留 source_run 和原始记录，交付时重新校验。变化页、编辑行为和重建验证仍按新任务完成。Agent 不得自行填入旧 passed。

action=views 按 offset 和 limit 返回当前任务必看文件的哈希、尺寸和路径。生成文件、收到索引或缩略图均不代表已看图。出现输出截断时重新按小批次打开，提交时只列实际查看的文件。

action=scene 可设置 scan_crops=true，按图片索引 offset 和 limit 检查疑似文字行。该本地启发式会漏检或把纹理识别为文字，不执行 OCR，不识别文字内容。crop_findings 返回素材像素区域，warnings 同时提供可能的图片遮挡。移动、缩放或重裁素材后，对照原素材与 Office 渲染检查残字、页码和正文，工具不会自动擦除。

正式安装的 agent_bridge 保持宿主标准输入输出连接，升级期间暂停派发，后端恢复后通知工具目录更新。不会重放写入或恢复过期 context_id，恢复后重新 bind 再查 status。旧版已经关闭的宿主连接无法由新程序接管，需宿主重新连接一次；后续连接才使用新守护入口。安装中断留下的更新标记须先核对安装日志和备份，不自动清除。
