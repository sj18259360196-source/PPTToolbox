PPT Toolbox 1.27.1

首次使用请运行 Setup.exe，选择程序、管理数据和项目目录。
已有安装继续使用原位置，日常从开始菜单中的 PPT Toolbox 打开。

在设置中接入制作 Agent，验证 MCP 后，从概况页复制制作指令。
驻留 PPTAgent 为可选功能，在 Agent 接入页配置 Responses API。
安装包不包含作者的 API 密钥或个人项目，用户自行填写服务配置。

项目列表使用文字索引，支持排序、文件夹、子项目、批量交付和归档。
点开项目查看工作路径、实际调用、异常和当前 PPT 预览。

版本与更新页提供检查、下载、取消、重试和安装。
默认每天检查一次，可关闭。签名及文件校验通过后才能执行安装。
有活动任务时等待，保留数据、设置、授权与项目位置。
旧版内置个人经验会转存到本机管理数据中，不对外发布。

桌面需要 Edge WebView2 Runtime 和 .NET Framework。
Office 制作与验收需要本机 PowerPoint。LibreOffice 预览不代替 Office 验收。
首次安装包尚未使用 Microsoft Authenticode 证书，Windows 可能提示未知发布者。

ZIP 用于明确选择的便携运行或开发验证，便携运行使用 --portable。
扩展工具包单独管理，切换扩展不回退整套软件。

组件素材路线
先看整页背景、分区与层次，再按组件类别和编辑要求选路。复杂插画与装饰标题默认参考局部生成，无需先试画或评分。简单插画与规则几何用原生对象，照片和已有清晰素材保留源像素及内部文字，页面独立文字保持原生。图片默认整体移动、缩放与替换，内部编辑由明确要求触发。
多个独立小素材可用 request.items 一次生成透明素材板，逐项裁切核对，仅补做失败项。装饰标题和生成插画可读文字须按原文核对实际图片。回装后查看全页与关键局部的左右图和叠图，并在副本中编辑、保存重开。
简单分层插画或指定内部编辑时，按需调用 graphics_illustration_guide，按部件选择钢笔节点或选区转路径。参数与步骤由当前工具契约返回，升级后重连 MCP。
