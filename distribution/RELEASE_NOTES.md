PPT Toolbox 1.21.1

面向 Windows x64 的公开发行版。

修复 GitHub 版本查询返回 415 的问题，版本信息与安装文件分别使用对应的 HTTP 请求头。

- 版本与更新页支持检查、下载、取消、重试和安装。更新清单使用 Ed25519 签名，安装包通过 SHA-256 校验。安装助手意外退出后显示中断原因，可重新检查和下载。
- 默认每天自动检查一次，可关闭。制作任务、驻留 Agent 或项目写入尚未结束时，安装进入等待。
- 升级保留安装位置、项目、授权、API 配置和用户指令。旧版内置个人经验转存到本机管理数据。
- 公开安装包不含作者的项目、原始复盘或密钥。使用固定版本和哈希重新构建 Python 运行环境，PDF 预览使用 PDFium。
- 保留文字项目索引、排序、子项目、批量交付与归档、工作路径图和可选的 Responses API 驻留 Agent。

早期版本（包括 1.21.0）用户先下载并安装本版，此后的更新可在软件内完成。

桌面需要 Edge WebView2 Runtime 和 .NET Framework。Office 功能需要本机 PowerPoint。首次安装包尚未使用 Microsoft Authenticode 证书，Windows 可能显示未知发布者提示。

程序代码采用 MIT 许可证。图标、医学素材与第三方依赖保留各自许可和署名要求。
