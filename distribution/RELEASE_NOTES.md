# PPT Toolbox 1.31.8 Windows

本次更新适用于 Windows x64，重点调整极速版的复核节奏，并让三档标注说明直接以完整文字提供。也包含自公开稳定版1.30.3以来的编辑能力默认设置、素材草稿、提交诊断和项目界面改进。

## 极速版集中检查

首个正式候选先集中查看整页左右图和叠图，一次列齐明显问题，再合并修复。后续按问题查看必要局部的左右图，并快速确认整页没有新增溢出、遮挡或布局错误，普通小改默认不再反复叠图。

整体清楚、内容及布局准确且无专项要求时，轻微字体、色差、圆角和柔和阴影差异可如实记录，避免持续装饰微调。错漏、错误关系和箭头、明显偏位、溢出遮挡、素材来源或编辑结构错误继续阻断交付。大幅布局变化、用户精确要求和显式频繁叠图设置仍按任务执行，不按修订轮数自动通过。

## 三档标注直接读文字

极速、标准和精修的新合同统一提供完整UTF-8 JSON标注说明，另附Markdown文档，并保留一张位置概览图。Agent直接读取文字，说明清单不再转换成多张PNG或图片PDF。

对象、坐标、制作路线、编辑能力、外观要求、风险和适用文字用例继续完整保留。文字阅读与看图分别记录，紧凑回包也提供完整原文，已经内联时无需重复读取文件。标准和精修的检查深度保持。

## 从1.30.3升级的其他变化

- 文本框默认按框宽换行，图片默认不锁宽高比。原生表格和图表可以放进组合及多层组合，保留单元格和嵌入数据。保存前清除适用的组合与图片比例锁，交付时检查残留锁。
- 当前合同允许时，待核对素材可以先保存为制作草稿，继续预览和原图核对。草稿接收与审查通过分别显示，正式交付仍须满足适用检查。批量区域问题和可独立判断的提交错误集中返回，减少逐项往返修改。
- 制作、项目运行路径与辅助Agent共用当前冻结合同的工作流上下文。标注生成、文字阅读、标注审核和最终验收分别记录，管理建议不能改写实际状态、证据或用户认可。
- 改进提交回执、故障关联和恢复说明。已接受结果与后续展示故障分别处理，结果未知时先核对现有记录，避免重复执行Office写入。
- 项目列表和详情统一显示制作档位及配色，整理状态与操作区域。运行路径默认展开历史轮次，继续保留各版本的失败、检查与交付记录。

## 升级与验证范围

升级继续使用已有安装位置、管理数据、项目目录、设置和授权。已签发编号与在制项目沿用各自冻结合同，不自动改写旧计划、标注产物、任务或历史证据；上述新标注与极速规则用于相应的新合同。

1.31.8已完成源码回归、Windows安装包构建和本机正式安装核验。这些记录与真实PPT效果分别计算。本轮没有新增真实Office成片、编辑效果或同参考图制作耗时验收，暂不提供提速比例。

本次不发布Mac同版安装包。Mac Apple Silicon继续使用现有[1.30.3独立测试版](https://github.com/sj18259360196-source/PPTToolbox/releases/tag/macos-trial-v1.30.3-20261025)，原临时签名、未公证和手动更新范围保持。

公开发行提供安装包、更新清单、校验文件、发行说明及所需第三方许可材料。完整应用源码在私有仓库维护，公开仓库自动生成的Source code归档仍对应历史公开源码。

# PPT Toolbox 1.30.2

本次更新适用于 Windows x64，集中补齐矢量制作与项目管理。

- PPT 与矢量项目进入同一项目目录。矢量详情沿用项目工作台的操作和样式，集中查看运行路径、文件、制作记录与助手摘要。
- 运行路径按所选版本显示签发要求、参考与画布、文档提交、结构检查、逐格式导出、PNG 检查和交付。当前执行服务、PPT 等待原因与助手状态单独显示，原始依据可展开。
- 历史版本保留自己的失败、检查与交付状态。新版本重新检查，交付后可继续修订；重复查询已交付版本返回原记录。刷新保留所选节点和缩放位置。
- 管理助手显示排队、处理和摘要过期状态。处理中残留的旧错误标注为上次摘要整理错误，助手依据已有记录整理摘要。
- 导出按格式记录完成、失败、部分交付和限制。Illustrator 兼容输出使用 SVG；PSD 保存像素图层与 SVG 伴随源文件。PDF、EPS 和字体限制见随包矢量说明，目标编辑器验收分别记录。
- 更新软件内说明、中文帮助、Agent 启动指令和 Skill，补齐 VEC 请求分流；发行包保留现行说明并排除私人项目、配置与原始历史记录。
- 桌面运行时更新至 Electron 44.9.3，包含受影响中间证书的撤销修复及同主线安全回补。修正发行包的图标缓存匹配，首次进入素材库可直接加载随包缓存。

本版沿用 PPT 的制作、授权和实际 Office 检查流程。升级继续使用已有程序、管理数据与项目位置。定向测试、隔离 Worker 与实际界面检查覆盖本次调整；本轮未新增真实模型效果、Office 制作或 Adobe 编辑器验收。

macOS Apple Silicon 继续使用单独发布的 1.28.1 试用包，其签名、安装和待验功能按该发行说明处理。本次没有新的 Mac 或 Intel 安装包。

完整应用源码在私有仓库维护。公开仓库提供软件发行、签名更新清单、校验文件和第三方许可材料。

# PPT Toolbox 1.27.15

文字校准支持小数逻辑画布，显式记录导出像素尺寸。例如 1672×940.5 的场景按 1672×941 像素导出，保留源场景的逻辑坐标、页面大小和文字格式。

修正真实 PowerPoint 对页面尺寸取整造成的校准误拒。先精确核对 PPTX 内的页面尺寸，再接受本机实测的最近 1/8 pt 回读值；实际改页大小、错误像素尺寸和过期缓存继续拒绝。旧整数画布计划仍可读取，旧小数画布计划需要重新生成。

128 项定向测试通过，5 组场景完成真实 Office 校准和复用，另用 10 组页面尺寸核对回读规则。原有 3 组渲染与修复前逐字节一致，5 组文字目检未见截字或溢出。这次修复减少误拒后的重复工作，尚未测量整页制作提速。

## 1.27.14

编辑验证任务自动准备对象清单和分批操作文件，保留所有必需编辑项及未完成原因。提交前重新核对候选文件与场景，减少手工整理和过期操作。

单层分组内的图片可准备移动、缩放操作，坐标按页面位置换算。嵌套分组、分组旋转或翻转等不支持情况仍明确待办。图片子对象验证不能代替整个素材组验收，也不会自动填写视觉通过。

两份历史 PPT 的独立副本已完成 14 张分组图片的真实 PowerPoint 保存、重开和回读验证。同尺寸渲染在预定编辑区域外没有像素变化。该结果限于这些样本，未测 GUI 拖拽。

升级继续使用原程序目录、管理数据和项目设置，保留权限及历史记录。真实 Office、视觉检查和正式交付要求继续生效。

图形预览增加超时、取消和状态查询。连接中断后可查询并取回已完成结果。历史编辑失败可以通过明确的修正证据解除对应阻挡，原始记录继续保留。

任务提交与阶段打卡分别返回结果和版本，便于只重试未完成部分。紧凑响应减少重复内容，完整响应可通过调用编号查询。当前约束、错误和未解决事项仍直接返回。

增加图片移动、缩放、旋转、替换和文字字号编辑接口。不支持的分组变换及操作组合会在执行前停止。新图片接口完成源码和自动测试，真实 PowerPoint 保存重开及 GUI 操作验收待后续。

两种版本共用制作要求与修改记录。Agent 通过 toolbox_manual 读取当前保存的要求和设置，按说明回读项目状态与交接文件。切换不清空草稿，复制前保存修改并刷新目录；另一窗口已经修改时保留本地草稿并提示冲突。

本次公开更新包含 1.27.0 至 1.27.5 的分层素材、路径预览、结构化预检、批量描边、组件审查、文字校准、修改影响建议和全局制作设置。新项目采用当前默认，已有项目保留自己的设置。视觉判断和实际编辑验证继续由制作 Agent 完成。

升级沿用已有程序、管理数据和项目位置，保留用户修改与权限。随包提供制作说明及公开校验清单，私人项目和原始反馈不进入公开包。
