# PPT Toolbox 1.21.3

修复旧版残留调用记录导致安装程序持续提示存在未决调用、无法升级的问题。

- 安装程序确认旧后台与调用进程停止、项目没有写入锁后，保留历史记录并继续升级。
- 沿用原安装位置、管理数据、设置、授权和项目路径。更新前备份，程序验证失败时回滚。
- 结果未知的调用继续保留原状态，不重放任务，不补写成功记录。
- 活动进程或无法确认的进程仍会阻止升级，并显示项目和调用编号。

升级前请退出旧版工具箱及对应 Agent 服务，然后直接运行本页安装包。无需卸载旧版或删除数据库。旧版若因历史记录无法发起软件内更新，请手动下载此安装包。

相关检查已覆盖数据继承、活动任务拦截和失败回滚。具体用户电脑上的升级结果仍以实际安装为准。
