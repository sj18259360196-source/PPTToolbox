# 版本与更新

软件界面只显示 PPT Toolbox 的发行版本。管理器、内置 PPT 制作工具、Skill 和随附说明由同一个安装包更新，采用同一发行号。

## 升级软件

从 1.21.0 开始，版本与更新页提供检查、下载、取消、重试和安装。默认每天自动检查一次，可关闭；检查只读取公开版本信息，不上传项目或调用 Agent。安装包和发行清单需要通过 Ed25519 签名及 SHA-256 校验。

早期版本先手动安装一次 1.21.0。之后可在界面中完成升级，也可运行新版完整安装程序。升级沿用已有安装位置、管理数据和项目目录。有活动任务或结果未知的调用时，安装进入等待；用户可取消排队。源码或便携预览需要手动安装。

下载失败不影响当前软件。安装替换失败会恢复本次替换的程序文件。管理数据库版本不兼容时停止更新，不能把旧数据库直接覆盖回正在使用的数据。初次安装包尚未使用 Microsoft Authenticode 证书；发行清单签名用于软件内更新验证。

版本与更新页提供更新说明和软件版本记录。记录从启用该功能后开始，在软件启动时登记读到的发行号和构建指纹。首次记录不代表首次安装，缺失的旧记录不会自动补成已安装历史。

## 扩展工具包

日常制作直接使用内置工具。需要独立扩展时，展开扩展工具包管理，选择 ZIP，检查内容与兼容范围后再导入。扩展保留自己的名称和版本，导入后保持停用，启用、信任和执行仍遵循原权限设置。

扩展可在 MANIFEST.json 中声明兼容范围。以下字段均可按需要提供，至少填写一个。

```json
{
  "compatibility": {
    "manager_api": "ppt-toolbox-manager/1",
    "min_product_version": "1.20.5",
    "max_product_version_exclusive": "2.0.0"
  }
}
```

上限不包含指定版本。已知不兼容的扩展无法导入或切换；没有声明范围的旧扩展会提示核对说明，不把缺失声明当作已验证兼容。

工具包切换记录只记录当前制作工具的变化。整套软件回退需要匹配的安装包与管理数据兼容检查，不能通过切换工具包完成。

## 诊断信息

诊断信息保留内置工具身份、接口协议、程序位置和构建指纹。接口协议与数据格式按各自的兼容性变化维护，历史项目记录保留创建时的版本。

## 维护发行号

release.json 是唯一手动维护的软件版本来源。修改它后，运行下面的命令同步 Skill 和插件元数据，再检查一致性。

```powershell
python -B scripts/release_info.py sync
python -B scripts/release_info.py check
```

管理器、制作脚本与打包程序读取同一份发布信息。发行清单和安装程序据此生成版本，元数据不一致会阻止打包。构建指纹继续由文件内容生成。

小修复递增最后一位，完整功能更新递增中间一位，破坏兼容的变化再调整第一位。已有安装记录、项目文件和旧发行包不改号。
