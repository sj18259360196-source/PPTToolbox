## Windows 1.31.30 准备进展

本轮围绕已制作 PPT 的继续返修和正确版本交付改进。

- 在同一项目中区分已保存草稿、当前候选、编辑副本和历史交付，按所选文件打开 PPT。
- 当前候选缺少预览时显示实际预览状态，历史交付单独可选。
- 完整 Setup 支持首次安装续装与升级中断恢复，恢复时检查文件、备份和外部改动。
- 安装前协调旧后台会话退出，后台注册查询使用哈希缓存，减少重复读取 PPT。

该版本已在维护者电脑完成完整 Setup 升级、发行文件校验及隔离项目的真实 Office 预览；安装版桌面与新建 Agent stdio 连接分别检查。多版本查询速度仍需改进，升级后的已有 Agent 对话可能需要手动重连。

公开安装包、签名更新清单与下载校验尚待发行核验。软件内稳定更新继续读取已发布的 1.31.26，Mac 测试版使用自己的独立发行。

## 升级软件

Windows 的版本与更新页提供检查、下载、取消、重试和安装。检查只读取公开发行信息，下载与安装由用户发起。更新清单签名和 SHA-256 核对通过后才能安装，有活动任务或写入锁时等待处理。

也可从[公开发行页](https://github.com/sj18259360196-source/PPTToolbox/releases)手动下载完整 Setup。升级沿用已有安装位置、管理数据、项目目录和用户设置，已签发编号与项目保留原合同。管理数据库不兼容时停止更新。

升级后若原 Agent 对话提示 `Transport closed` 或仍显示旧工具，重新连接客户端中的 PPT Toolbox MCP 服务。客户端没有重连入口时，重启客户端后再检查接入结果。恢复连接后先查询原任务状态，避免重复执行已经完成或结果待确认的操作。

安装器尚无 Microsoft Authenticode 发布者证书，Windows 可能显示未知发布者提示。更新清单的签名和文件哈希用于核对发行文件，与 Windows 发布者签名分别检查。

Mac 测试版手动安装更新，步骤见 [Mac 测试说明](https://github.com/sj18259360196-source/PPTToolbox/releases/download/macos-trial-v1.30.3-20261025/MACOS_TESTING.md)。

## 版本与验证

软件界面显示实际安装包的发行版本。管理器、内置工具、Skill 和随附说明由同一安装包更新；扩展工具包继续保留自己的版本和信任设置。

源码测试、安装包构建、本机安装、Agent 客户端连接和 Office 检查各自留存结果。某个环节通过不会自动改变其他环节的状态，具体 PPT 的外观和编辑效果继续按项目验收。

软件版本记录从启用记录功能后开始保存实际读到的发行号和构建指纹，缺少的历史不补写成已安装记录。

## 公开源码归档

完整应用源码在私有仓库维护。公开仓库保留历史源码，根目录的 `release.json` 仍标识历史源码版本。GitHub 自动生成的 Source code 归档对应这些历史文件，不能用来构建 1.31.26 或待发行的 1.31.30。

当前安装包以实际 Release 附件为准，第三方依赖所需的许可和对应源码继续随发行提供。
