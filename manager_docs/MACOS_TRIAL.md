# macOS Apple Silicon 1.30.3 测试版

本测试版适用于 M 系列 Mac，系统要求为 macOS 14 或更新版本。安装包使用临时签名，尚未经过 Apple 公证，采用手动下载安装。下载入口为 [GitHub 测试版](https://github.com/sj18259360196-source/PPTToolbox/releases/tag/macos-trial-v1.30.3-20261025)。

本版从当前 1.30.3 源码构建，包含制作准备页、PPT 与矢量项目管理、矢量版本及运行路径、逐格式导出记录、助手摘要和现行制作说明。具体格式能力以本机检查结果为准。已在 Apple M4、macOS 15.7.3、PowerPoint 16.102.2 上验证副本编辑、裁切、保存重开，以及 PowerPoint PDF 经 PDFium 生成 PNG 的流程。直接原生 PNG 保存仍不可用；Mac 文本边界、复杂原生对象、Intel 与跨版本仍未验收，Adobe/Corel 编辑器兼容性须另测。

## 安装

1. 下载 `PPTToolbox-1.30.3-arm64-trial.dmg` 并打开。
2. 退出旧版 PPT Toolbox，保留旧应用副本，将新版拖入 Applications。
3. 从 Applications 启动。若系统拦截未公证应用，尝试打开一次后，到系统设置的隐私与安全性中选择仍要打开。若仍无法启动，保留完整提示或截图用于反馈。
4. 已有管理数据继续保存在 `~/Library/Application Support/PPTToolbox`。首次启动后核对项目列表、设置和项目保存位置。

## 建议测试顺序

1. 检查启动、窗口名称、主题切换、文件定位和退出后重新启动。
2. 检查制作准备页的提示词复制、项目编号、制作设置、项目列表和历史版本。
3. 用新建测试项目检查矢量制作入口、版本选择、运行路径、预览与所需导出格式，记录具体失败步骤和错误原文。
4. 在 Agent 接入页检查当前客户端和连接结果。临时签名包的外置监督进程仍受正式 Developer ID 要求限制，遇到限制时保留检测结果。
5. PowerPoint 测试使用演示文稿副本，分别记录打开、保存、重开、属性回读和原生导图结果。

反馈请附上应用版本、Mac 芯片、macOS 版本、PowerPoint 版本、操作步骤、预期结果和实际结果。出现错误时保留原文、截图及该次测试的诊断文件，以便继续定位和修改。
