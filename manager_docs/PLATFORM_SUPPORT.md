# 平台功能对照

Windows 当前公开稳定版为 1.29.1，1.30.2 正在准备发行；Mac Apple Silicon 试用版保持 1.28.1。共享源码与界面按各平台安装包分别交付，Office、签名和系统接入分别验证。

| 项目 | Windows x64 | macOS Apple Silicon | macOS Intel |
| --- | --- | --- | --- |
| 安装包 | 1.29.1 完整 Setup 与签名更新清单 | 临时签名 DMG，手动更新 | 暂未发布 |
| 项目、设置、主题 | Electron 桌面与现有功能 | 共享界面，原生 Mac 启动检查 | 暂无安装验收 |
| 项目编号与空间 | 随机编号、编号检索与复制、空间统计、批量清理 | 使用同版共享界面和管理逻辑 | 暂无安装验收 |
| 制作 Agent、CLI、MCP | 现有正式接入流程 | 正式外置监督流程要求 Developer ID，当前临时签名包不支持 | 暂无安装验收 |
| Office | 依赖本机 Windows PowerPoint | 八类编辑路径已有实现，实际编辑、保存读回与视觉效果待实机验收 | 尚未开放 |
| 自动更新 | 正式渠道签名清单 | 稳定自动更新关闭 | 暂无更新包 |
| Apple 签名与公证 | 不适用 | 临时签名，未公证 | 暂无安装包 |

Mac 原生对象新建、局部富文本等能力尚未完成。跨 Windows 与 Mac 的完整项目迁移、不同 Office 版本和不同系统组合继续分别验收。

公开应用源码仍为 1.27.15 历史快照，后续开发源码在私有仓库维护。公开源码归档不能用于构建新版安装包。Windows 1.30.2 的独立矢量空间不属于 Mac 1.28.1 的已发行范围。
