# Agent 实时状态

左上角名称下方显示当前工具箱的 Agent 状态，点击文字可进入接入设置。

- 绿色表示至少一个 Agent 正在调用工具箱工具。
- 蓝色表示 MCP 会话已连接，当前没有正在执行的调用。
- 红色表示某个已连接会话最近调用失败。设置页显示错误和日志入口，下一次成功调用后恢复蓝色。
- 灰色表示当前没有有效连接。仅写入配置或完成本机自检不会显示已连接。

窗口可见时每两秒读取状态，最小化、隐藏到托盘或浏览器页面隐藏时暂停，重新显示时立即读取。隐藏时取消尚未完成的界面请求，过期响应不会覆盖恢复后的状态。此行为只暂停界面刷新，MCP 会话心跳和 Agent 任务继续运行。

客户端正常关闭后显示未连接，异常退出时最多等待十二秒使旧会话失效。多个客户端同时连接时分别列出，顶部优先显示工作中，其次显示错误，再显示已连接。设置页仍显示每个会话的单独状态。

此状态只能反映 Agent 通过工具箱 MCP 进行的活动，无法观察它在其他软件中的工作。空闲连接与一次性口令验证分开显示；验证通过不会让已经退出的客户端继续显示在线。本机自检不计入外部连接。

状态数据独立保存在管理数据目录中的 agent-runtime.sqlite3，不改变项目授权、执行开关和用户配置。
