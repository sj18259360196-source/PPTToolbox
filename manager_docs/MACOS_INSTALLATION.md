# Mac Apple Silicon测试版安装

当前独立测试版为1.30.3，适用于M系列Mac和macOS 14及以上。下载[1.30.3测试DMG](https://github.com/sj18259360196-source/PPTToolbox/releases/download/macos-trial-v1.30.3-20261025/PPTToolbox-1.30.3-arm64-trial.dmg)，按同一发行页的SHA-256核对，再将应用拖入Applications启动。

测试包使用临时签名，尚未Apple公证，采用手动安装更新。本次Windows1.31.20不替换Mac附件，也不改变该测试包的实际能力。Intel安装包尚未发布。

测试版通过包内Python直连Agent，正式外置监督流程要求Developer ID。已有验证包括副本编辑、裁切、保存重开、主工作流和快速制作，具体环境与限制见[Mac测试说明](MACOS_TRIAL.md)及[测试与反馈](https://github.com/sj18259360196-source/PPTToolbox/releases/download/macos-trial-v1.30.3-20261025/MACOS_TESTING.md)。
