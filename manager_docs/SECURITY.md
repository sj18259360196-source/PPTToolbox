# 管理范围与安全说明

本软件是本机控制面，不是强安全边界。使用管理器的人与同一账户的其他进程仍然能直接读写数据或运行原脚本。

- HTTP只绑定127.0.0.1；验证Host与Origin；API需要每次启动的Bearer令牌。令牌只放启动URL fragment，不写访问日志。静态页面和API加CSP、禁止框架嵌入及nosniff。
- 浏览器没有任意shell接口。诊断仅允许3项固定本地命令；导入工具包诊断前必须信任并启用。CLI执行显式argv，不使用shell拼接。入口策略无法拦截工作流内部模块，不能替代Codex沙盒。
- ZIP路径、大小、文件数、重复名称、符号链接、加密、敏感文件后缀和MANIFEST一致性均检查。导入不执行setup、钩子或依赖安装。
- 不扫描其他插件、密钥和聊天。不写用户已有config.toml或已安装缓存。注册本地来源需要预览确认，保持其他marketplace字段并备份；预览后文件变化则拒绝继续写入。
- 用户指令可改变Agent行为，应像代码一样审阅。Skill/手册编辑保存为独立覆盖，不写入原版。MCP返回的是用户当前选用的内容，不证明其无风险。
- 常见密钥、认证字段脱敏不是DLP保证。导出包含本机路径与指令文本，分享前检查。无遥测、无自动更新请求、无内置远程生图代理。
- 管理数据库和导出文件继承本机用户文件权限，不做数据库加密。用户有敏感内容时应使用操作系统的目录访问控制和磁盘加密。

Windows启动脚本、真实Codex插件安装以及真实Office没有在本次Linux环境中验证。MCP标准消息、配置生成和临时HOME的市场写入已测试；这不能代替目标宿主验证。
