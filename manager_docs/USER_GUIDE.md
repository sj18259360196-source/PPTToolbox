# PPT Toolbox 使用说明

新标准与精修编号冻结 `workflow_profile`，使用[1.30.4制作流程](../references/standard-refined-1304.md)。项目工具箱显示参考图、页面标注和当前PPT，JSON与Markdown保留完整说明。标注供制作时对照，不作为新的验收合同。极速与历史编号继续各自冻结规则。

新项目的标注与极速版采用相同的元素分类和编号样式。展开文字说明可按N01、B02等编号查看元素名称、制作路线、可改范围及必要备注。制作Agent结合实际PPT和Office图判断返修，标准与精修继续各自的验收安排。旧标注保留，明确重做时生成新版本。

极速版首版优先默认开启，已记住关闭的选择继续生效。1.31.15新增能力沿用各档当前流程，原生图形内的文字进入适用的原文、字体和编辑检查。对齐、表格格式、渐变阴影与文字底色组件的操作入口见[原生工具](../references/native-agent-tools.md)。已签发编号继续读取其冻结要求。

PPT 与矢量项目共用项目页，矢量项目的创建、逐版交付与格式范围见[矢量项目使用说明](VECTOR_SPACE.md)。下文的制作设置、PPT 阶段打卡与历史清理按 PPT 项目说明。

## 新手教程与高级操作

顶部的新手教程通过深色遮罩和高亮位置引导第一次制作。先从左侧 Agent 接入复制通用接入提示词，发给正在使用的 Agent；收到回复后查看接入记录，再设置项目目录，选择制作档位，并把制作提示词和参考图发给 Agent。

复制、连接、目录选择与保存、参考图准备和发送确认都可单独跳过。结束页会保留待处理项，可以回到相应步骤重试，或复制说明交给 Agent。底部的跳过教程用于退出整个教程；下次打开不再提示保存到工具箱管理数据，换端口启动后仍生效，顶部入口仍可手动重看。

项目段使用明确标记的参考案例说明参考图、下方的 PPT 预览、打开 PPT 和项目文件入口。案例不登记为用户的制作项目，打开 PPT 在案例中展示已有预览，正式项目仍使用本机的 PowerPoint 打开实际文件。

学习高级操作提供五项可选主题，包括本次设置与全局默认、同一项目继续制作与返修、批量管理与归档恢复、可选的小模型整理助手和制作 Agent 的 MCP 接入。阅读标记保存在当前浏览器中，打开说明不会执行项目修改。

Agent 接入页上方提供制作 Agent 通用接入与连接诊断，下方可选助手负责记录整理、摘要与管理辅助。教程分别定位到制作区或助手区。助手未配置时仍可通过外部 Agent 使用工具箱制作流程。

## 矢量项目

在设置的实验室中开启矢量空间，选择输出格式并复制带 VEC 编号的完整提示词，连同参考图交给制作 Agent。已有项目统一从项目页进入，可搜索、分类、排序、整理、归档和恢复。关闭入口后仍可管理已有项目。

PPT 项目内提供运行路径、项目文件、制作记录三个页签。矢量项目另保留项目资料，展示项目事实、冻结设置与格式限制。摘要、管理备注和助手状态通过带项目编号的工具箱助手入口在统一页下方查看。已有交付时默认显示最近交付版本，也可切换到任一历史版本；较新的制作版本单独提示。所选版本的失败、拒绝、部分交付和文件待核对按该版本显示，不沿用整个项目的交付状态。

运行路径分为签发与冻结设置、所选版本制作记录、全项目当前服务与管理。选择节点可查看真实结果与下一步，并打开关联文件、记录、预览或助手；路径和文件摘要在来源折叠区。助手可整理矢量记录和管理备注，不能执行 PPT、改写矢量制作状态或替代逐版看图检查。

返修时在同一项目提交新版本，旧交付和检查记录保留。PPT 的批量交付、交付并完结及历史清理会跳过矢量项目。各格式限制、恢复条件和完整步骤见[矢量项目使用说明](VECTOR_SPACE.md)。

## 实验室捷速版

在设置的常规与权限页底部开启捷速版并保存，制作准备页会显示独立捷速版指令。点击确认使用并复制捷速版指令，将它与参考图一起交给 Agent。每次确认签发独立 QPT 编号；普通提示词仍走原流程。

捷速版保留可编辑文字和主要布局，支持简单图形、原生表格及独立图片，简化精细装饰和逐区域调整。生成后集中检查实际 PowerPoint 页图及代表性编辑，最多返修一次。任务未通过时保留具体问题，不自动转入普通版。已有普通项目也不能切换为捷速项目。

关闭开关后停止捷速项目的新写入，已有成品和状态仍可查看。Agent 无法自行开启开关或签发确认。更多边界见 references/quick-mode.md。

## 制作设置

新签发极速0.6、首版优先0.7及标准、精修0.4合同的标注说明统一直接读文字。Agent任务内包含完整plan.json，Markdown便于人工核查，位置总览图继续保留。不再把文字清单生成多张图片或图片PDF，检查深度仍按所选档位执行。已签发编号和旧项目使用原合同，详见[制作与交付要求](../references/acceptance-guide.md)。

项目首页的全局制作设置管理新项目默认，制作准备页和设置页也保留入口。项目顶部和新建制作页可单独修改本项目。首次默认优先生成插画图片，可选择可编辑绘制优先；简单线性和几何图标继续保留原生编辑。照片按具体保真要求处理，背景与独立图标分开制作。

字体可选择相近字体优先或精细匹配。文本框可选择段落优先或逐行优先，均保留原生文字，不跨栏或卡片合并。Agent 查询、当前任务与审查会读取相同设置。

极速版下方的首版优先提交默认开启。开启后 Agent 完成全部页面，实际查看当前左右图，只核对原文、数字和元素是否齐全可见。缺项只补齐，位置和外观细节等用户反馈后再调整。核对通过后交付同一份首版 PPT，本轮结束。右侧的记住我的选择可保存开或关，后续多次新建继续使用该选择，切到其他档位再回极速时恢复。不勾选时只影响当前新项目，取消记住后后续新项目默认开启。已发放编号的选择保持冻结，调整下一份新项目后复制新编号；原首版和后续修改分别留存。中英文规则见[首版交付](../references/first-complete-delivery.md)。

未开启首版优先提交时，叠图检查可选择标准或频繁。标准模式首次全页必看叠图，后续按需；频繁模式每个新版本的全页及必查局部都查看叠图。极速 0.5 和 0.6 合同在标准模式下集中完成首轮左右图和叠图检查，合并修复后按需局部左右复核和整页快检。已真实查看首轮叠图后，普通小改不再重复叠图，轻微装饰差异按冻结容差记录并收尾。大幅布局变化及用户精确要求仍按任务检查，已签发旧合同保持原规则。详见[极速制作与验收](../references/fast-review.md)。字体规范可启用白名单，设置中文默认、英文及数字字体，并为标题、正文、表格、图表和图注指定中文字体；指定字体必须属于白名单。图片内部文字仍需实际看图检查。

全局选项只作为新项目默认。项目中途修改默认用于未完成部分，可勾选已完成区域纳入修订。窗口分别显示已保存、工作流已应用和待应用状态。旧项目显示沿用原项目策略，明确采用后才更新后续任务。制作偏好不会开启被禁用的服务或扩展权限。

## 提示词与项目编号

提示词页支持仅本次项目设置和保存为全局默认。本次设置只用于下一份新项目，复制时保存随机编号及本次要求，随后立即恢复全局默认。再次发送同一项目时，使用再次复制上次项目，沿用原编号和创建时的设置。修改下一份草稿不影响已发出的编号。可以连续创建多个编号，无需等待前一个项目注册。Agent 先调用 `toolbox_prompt_project` 传入 `prompt_id` 读取完整要求，再用相同编号调用 `toolbox_project_bind` 绑定明确的项目目录或名称。一个编号只绑定一个项目；初始化失败先查询原状态。

项目列表支持按编号搜索。项目详情和制作设置都显示编号，并提供复制编号按钮。把编号发给 Agent 后，Agent 可查询已绑定的目录，再继续修改该项目。旧项目没有提示词编号时，界面显示原项目编号。

注册后，`workflow/project-prompt.json` 保存创建时的要求，`workflow/project-settings.json` 保存设置与变更记录，提示词页准备下一个新项目。用户在对话中更改项目要求时，Agent 读取当前设置与 revision，再通过 `toolbox_project_settings_update` 保存明确的修改范围；它不能修改全局默认或执行权限。已保存与当前任务已应用分别核对。完整合同见[制作设置](../references/production-settings.md)。

## 从制作准备页开始

首次接入先打开左侧 Agent 接入，在上方复制通用接入提示词，发给正在使用的外部 Agent。完成连接后回到制作准备页，把制作提示词与参考图一起发给它。制作 Agent 通过 MCP 或受管 CLI 建立项目、调用工具并交付 PPT。下方可选 PPTAgent 用于整理记录、检索经验、按已有规则处理申请、更新工作图和保存管理备注。

制作要求可直接编辑，点击保存修改或复制完整提示词时保存。修改记录可查看和恢复最近 30 次历史版本，恢复会另存为新版本。程序、管理数据、默认项目目录、全局制作设置及授权规则在每次复制时重新生成，修改目录设置后无需重写提示词。完整预览显示实际复制内容。

制作准备页保留工具、Skill 与权限信息，并提供 Agent 接入入口。连接诊断集中在接入页，分别展示配置、本机 MCP、自身客户端调用和 CLI 检查，不用全局会话数判断某个项目是否在制作。

## 在软件内准备图片（可选）

点击左侧的新建制作，填写项目名称并选择项目根目录。工具箱会建立独立工作区，将上传图片另存到 input。原图片不会移动或改写。图片支持排序、同名区分和重复检查，保存后关闭软件也能从项目页继续。

填写要求并保存后，复制制作指令，发给已经接入的 Agent。指令包含当前安装路径、规则、输入图片绝对路径和工作流项目位置。准备工作区中的 project 子目录由工作流初始化，新建向导不提前占用它。若工作流已建立，Agent 应读取状态后续作。

项目执行继续遵循执行开关、项目授权和工具权限。工具箱不会自动发送对话。手动审批时，在项目页核对输入与输出路径后批准。操作结果未知时，应查询原请求，避免重复写入。

## 查看与修改项目

项目页显示登记索引，新增、改名、归档、排序或交付状态变化时更新列表。点击已登记项目的名称后加载文件和工作记录。已完结和已归档页会自动显示项目占用的磁盘空间，也可点击刷新容量。子项目单独统计，制作中和成品页不显示容量。项目文件夹可展开子项目，项目内部提供路径导航和新建子项目入口。

项目页初始按最近活动优先显示。切换到手动顺序后，每行的排序菜单可以上移、下移、移到最前或最后，顺序保存到管理数据库。子项目在同一上级内排序。也可选择较早活动优先、名称正序或名称倒序。

勾选项目后可批量归档或批量交付。全选包括当前筛选结果中的子项目，单独勾选父项目不会连选子项目。批量交付用于 PPT 项目，先核对各项目要保留的 PPT；混合选择会跳过矢量项目与启动申请。只完成成功项，未完成项保留勾选和原因。

归档项目及其成品统一移到已归档页，成品页只列出未归档项目的成品。归档保留项目文件和历史记录，可单独或批量恢复。归档与交付完结分别处理。

已归档页为 PPT 项目显示未清理、已清理、部分清理或清理中。勾选项目后点击批量清理，先核对各项目的待删除目录、文件数量、预计释放空间和保留成品，再确认永久删除。只清理已完结的 PPT 项目；矢量项目保留源文件和版本，不提供历史清理。成品缺失、内容改变、仍在写入或被其他项目用作输入时会阻止清理，其他符合条件的项目继续处理。成品 PPT、参考图、素材、项目编号、制作设置、提示词和清理记录会保留，清理后的容量自动更新。

项目详情的制作设置、打开文件夹、项目说明和新建子项目按钮在同一行对齐，当前制作策略显示在下一行。

等待 Agent 启动的条目属于尚未登记的启动申请，可点归档申请，也可勾选后批量归档，无须先建立项目文件夹。已归档申请需先恢复才能继续启动。混合批量交付会跳过这类申请，并继续处理已登记项目。

软件或受管 Agent 创建项目时自动登记。外部移动或导入目录后，点扫描文件夹恢复索引。项目内的结构化事件与状态文件用于保存工作记录，ppttool.md 保留为可读说明。每个子项目都有独立身份、文件和工作链。

点开项目查看大阶段、当前安排、实际调用、异常记录和工作分支。制作 Agent 只在接单、方案、制作、修订、交付切换及最终收尾时打卡，阶段内由软件自动观察。正常六次登记，改道、阻塞和暂停按需补充。工具启动、工具结果和阶段声明分别显示，失联不会自动变成失败或完成。

制作 Agent 先读取当前项目已生效的制作设置，分析整页背景、分区、前后层次和内容归属。图片生成优先时，复杂插画与装饰标题可参考生成独立高清素材，用 generation_decision 的 content_category 记录决策，无需先绘制或填写分数。可编辑绘制优先时，拆分真实原生部件并验证内部编辑。简单图标和规则几何保留原生对象，照片按具体保真要求处理，已有素材按来源、质量和编辑要求复用。独立页面文字保持原生，素材内部文字随所属素材保留。

多个独立小素材可用 request.items 生成一张透明素材板，每项保留自己的参考、文字约束和决策，按实际主体逐项裁切、核对和登记，仅补做失败项。request_assets 表示多个素材任务提交。默认工作图显示组件路线、生图、可选裁切与回装；旧 low_similarity 记录继续显示实际试稿与低于 75% 的 Agent 判断。

生成标题逐字核对，生成插画内嵌字须查看真实产物并提交 material_text_checks；模糊字不猜写。保留原件的照片内部文字随原件保留，不擦字后覆盖原生文字。允许参考生成的照片仍需核对可读原文与事实准确要求。回装后查看同版本全页及关键局部的左右图，按当前检查模式与任务必看清单查看叠图，在副本中验证整体编辑与保存重开。

PPT 区域只显示当前 PPT 的简单预览、页码和打开文件入口。历史版本保留在项目中，需要时由 Agent 查找。软件自动发现 PPT，并匹配哈希一致的成功渲染记录。暂无匹配图片时显示预览待更新，可以直接打开 PPT。项目界面不再提供元素检查、对象树、叠加图或对比功能。

项目说明按钮可编辑 ppttool.md 中的人工备注。软件只更新自动记录区，保留人工说明；并发修改会提示重新读取合并。API 未启用或断线时，本地打卡和文件记录继续更新。

左侧 Agent 接入页下方填写可选 PPTAgent 的完整 Responses API 地址、模型和 Key。保存后可测试连接，测试包含一次工具调用和结果回传，不读取项目内容。启用后，项目记录变化会触发后台摘要，也可在管理助手中提交任务。模型接收任务文字、相关项目记录、文件名和工具结果。Key 由 Windows 加密保存在本机。

PPTAgent 只使用界面列出的管理工具，制作和大阶段打卡仍由制作 Agent 完成。批量交付、归档和排序直接在项目页操作。API 未启用或暂时不可用时，本地工作链继续记录。兼容设置中的 Chat Completions 仅支持辅助摘要。

## 素材与图形

素材库集中提供搜索、外观匹配、来源与许可、人工检查、SVG 导入、版本编辑和重绘入口。加入项目会保存项目素材，实际放入页面由当前制作任务完成。

图形构造位于素材库的同级页签，可编辑配方、预览、生成项目草稿、重新载入和拟合渐变。服务不可用或项目未授权时会显示错误，不能把草稿生成当作最终 Office 视觉验收。

## 经验与组件

经验库提供随包的通用方法和指令模板，也合并本机经用户同意收录的项目经验。新安装即可检索内置方法，实际数量以当前查询为准。公开包只提供脱敏方法摘要，私人项目与原始历史复盘不随包发布。组件技能入口保留来源收集、待提取、参数、状态与复用记录。是否自动收录新交付项目可在组件页设置。收录来源不等于技能已验证或已启用。

项目工作链会推荐最多三条相关经验。制作 Agent 在已有阶段打卡中记录实际采用的经验编号，无需增加一次引用操作。推荐次数、报告采用和结果证据分开统计，历史经验不会自动变成本次验收通过。详细登记合同见 references/project-work-chain.md。

## 制作 Agent 接入方式

打开 Agent 接入页上方，复制通用接入提示词，发送给当前 Agent，由它识别实际宿主和配置作用域。页面不要求用户先选客户端。提示词包含当前安装的实例、启动命令、配置示例和受管 CLI 读取入口，复制本身不写配置或生成验证口令。

接入只合并本工具箱 command/args，修改前备份，保留其他服务和已有策略。正确条目跳过写入，显式禁用保持禁用。同名来源不明、重复服务、自定义配置无法安全合并或并发变化时停止并说明具体待办。接入不创建项目、不修改执行权限，也不调用下区助手模型 API。

客户端支持刷新时使用其原生能力，需要重载扩展或新会话时给出准确操作。实际可用时再生成十分钟有效的一次性口令，由当前客户端调用验证工具和 context。多个请求独立保存，通用客户端未核对配置文件时如实标明。本机自检和 CLI 可用分别留证，不代表当前对话已加载 MCP。

上区高级设置保留制作执行、新项目审批、配置示例及 MCP 诊断。下区配置可选助手 API，并按选定项目查看摘要、备注、用量和处理记录。项目入口会带入编号，未知项目会提示，不能回退为全部项目操作。

## 设置、规则和更新

接入配置、诊断与助手工作区集中在 Agent 接入页。常规设置继续保留目录、通用执行环境、网络评测等原有设置，制作规则、工具与指令、软件与扩展包、通用插件来源和日志按原用途组织。自动批准只处理符合现有规则的新申请，拒绝或归档的申请保持原状态。制作执行开关用于受管 MCP 和 CLI 调用，PPTAgent 的 API 启用单独设置。

制作 Agent 的分项接入状态在统一页上方查看，PPTAgent 的 API 连接与处理记录在下方查看。使用统计记录经验、工具、图标和组件技能的使用次数；采用经验可随阶段打卡登记。归档不清除历史统计，模型 Token 和费用仍在 API 服务商处查看。

帮助从当前随包文件读取。安装包统一更新程序、随附说明书和内置 Skill，用户覆盖保存在管理数据中。随包原文变化后，覆盖文档会显示核对提示。比较原版、合并保存或恢复原版后，再刷新 Agent 上下文。制作指令模板也能保存用户覆盖，新建制作每次复制都会读取当前内容和目录设置。

软件升级可在版本与更新页检查、下载和安装，也可运行新版 Setup.exe。早期版本需先手动安装 1.21.1 或更新的完整安装包。自动检查默认每天一次，可关闭；下载和安装由用户发起。签名和文件校验失败会停止更新，有活动任务时等待。安装沿用原管理数据与项目位置。ZIP 导入仍只用于扩展工具包。

管理配置导出不包含完整 PPT 项目。完整项目文件保留在各自工作目录，新建准备任务可以单独导出原图和指令。分享导出物前请检查业务内容和本机路径。

## 软件版本与项目运行路径

版本与更新页显示统一的软件发行号，内置制作工具随安装包更新。独立扩展在折叠区导入与切换，具体规则见[版本与更新](VERSIONS.md)。

项目顶部会显示调用失败、等待原因和结果待确认；选择步骤可进入关联功能或查看调用详情。点开项目后可查看自动排布的运行路径，分支与汇合由步骤关系生成。选择方框查看详情，可缩放或适应宽度。大阶段打卡继续沿用，阶段内无需逐工具汇报。制作 Agent 与驻留 PPTAgent 的更新方式见[工作图说明](../references/project-work-graph.md)。


## 1.26.7 插画方法直接入口

简单分层插画或明确要求内部编辑时，按需调用 graphics_illustration_guide，按实际观察选择钢笔节点或选区转路径，再调用 graphics_route_illustration。指南直接返回当前参数、受管调用入口、步骤和复查条件，不依赖经验检索。保留孔洞与共享边，分别验证轮廓、颜色和编辑行为。详见 [Agent 调用指南](../references/illustration-agent-guide.md)。软件图形构造页可读取并复制整套调用步骤；升级后重连 MCP。
