# PPT Toolbox 使用说明

## 从概况页开始

在概况页复制完整提示词，将它与参考图片一起发给 Codex 等制作 Agent。制作 Agent 通过 MCP 建立项目、调用工具并交付 PPT。左侧 Agent 接入配置的是工具箱内的 PPTAgent，负责整理记录、检索经验、按已有规则处理申请、更新工作图和保存管理备注。制作 Agent 的 MCP 配置位于设置中的制作 Agent 接入。

制作要求可直接编辑，点击保存修改或复制完整提示词时保存。修改记录可查看和恢复最近 30 次历史版本，恢复会另存为新版本。程序、管理数据、默认项目目录及授权规则在每次复制时重新生成，修改目录设置后无需重写提示词。完整预览显示实际复制内容。

概况页同时显示 Agent 连接、工具、Skill 与权限状态。窗口可见时每 2 秒刷新连接状态，最小化或隐藏后暂停，重新打开立即刷新；后台 Agent 任务继续执行。

## 在软件内准备图片（可选）

点击左侧的新建制作，填写项目名称并选择项目根目录。工具箱会建立独立工作区，将上传图片另存到 input。原图片不会移动或改写。图片支持排序、同名区分和重复检查，保存后关闭软件也能从项目页继续。

填写要求并保存后，复制制作指令，发给已经接入的 Agent。指令包含当前安装路径、规则、输入图片绝对路径和工作流项目位置。准备工作区中的 project 子目录由工作流初始化，新建向导不提前占用它。若工作流已建立，Agent 应读取状态后续作。

项目执行继续遵循执行开关、项目授权和工具权限。工具箱不会自动发送对话。手动审批时，在项目页核对输入与输出路径后批准。操作结果未知时，应查询原请求，避免重复写入。

## 查看与修改项目

项目页以纯文字显示登记索引，新增、改名、归档、排序或交付状态变化时才更新列表。点击已登记项目的名称后加载文件和工作记录，空间统计需点开查看存储。项目文件夹可展开子项目，项目内部提供路径导航和新建子项目入口。

默认采用手动顺序。每行的排序菜单可以上移、下移、移到最前或最后，顺序保存到管理数据库。子项目在同一上级内排序。也可改为最近活动优先、较早活动优先、名称正序或名称倒序。

勾选项目后可批量归档或批量交付。全选包括当前筛选结果中的子项目，单独勾选父项目不会连选子项目。交付前先核对各项目要保留的 PPT；只完成成功项，未完成项保留勾选和原因。

归档项目及其成品统一移到已归档页，成品页只列出未归档项目的成品。归档保留项目文件和历史记录，可单独或批量恢复。归档与交付完结分别处理。

等待 Agent 启动的条目属于尚未登记的启动申请，可点归档申请，也可勾选后批量归档，无须先建立项目文件夹。已归档申请需先恢复才能继续启动。混合批量交付会跳过这类申请，并继续处理已登记项目。

软件或受管 Agent 创建项目时自动登记。外部移动或导入目录后，点扫描文件夹恢复索引。项目内的结构化事件与状态文件用于保存工作记录，ppttool.md 保留为可读说明。每个子项目都有独立身份、文件和工作链。

点开项目查看大阶段、当前安排、实际调用、异常记录和工作分支。制作 Agent 只在接单、方案、制作、修订、交付切换及最终收尾时打卡，阶段内由软件自动观察。正常六次登记，改道、阻塞和暂停按需补充。工具启动、工具结果和阶段声明分别显示，失联不会自动变成失败或完成。

插图默认先绘制。Agent 判断局部相似度低于 75% 时可以使用参考图生成透明背景素材，用户明确要求优先。生图请求附带判断记录后，默认工作图自动显示绘制、相似度判断、AI 生图及回装节点；同图生成多个图标时增加裁剪节点。分数来自 Agent 判断，后续仍需检查 PPT 中的实际效果。

PPT 区域只显示当前 PPT 的简单预览、页码和打开文件入口。历史版本保留在项目中，需要时由 Agent 查找。软件自动发现 PPT，并匹配哈希一致的成功渲染记录。暂无匹配图片时显示预览待更新，可以直接打开 PPT。项目界面不再提供元素检查、对象树、叠加图或对比功能。

项目说明按钮可编辑 ppttool.md 中的人工备注。软件只更新自动记录区，保留人工说明；并发修改会提示重新读取合并。API 未启用或断线时，本地打卡和文件记录继续更新。

左侧 Agent 接入页填写 PPTAgent 的完整 Responses API 地址、模型和 Key。保存后可测试连接，测试包含一次工具调用和结果回传，不读取项目内容。启用后，项目记录变化会触发后台摘要，也可在管理助手中提交任务。模型接收任务文字、相关项目记录、文件名和工具结果。Key 由 Windows 加密保存在本机。

PPTAgent 只使用界面列出的管理工具，制作和大阶段打卡仍由制作 Agent 完成。批量交付、归档和排序直接在项目页操作。API 未启用或暂时不可用时，本地工作链继续记录。兼容设置中的 Chat Completions 仅支持辅助摘要。

## 素材与图形

素材库集中提供搜索、外观匹配、来源与许可、人工检查、SVG 导入、版本编辑和重绘入口。加入项目会保存项目素材，实际放入页面由当前制作任务完成。

图形构造位于素材库的同级页签，可编辑配方、预览、生成项目草稿、重新载入和拟合渐变。服务不可用或项目未授权时会显示错误，不能把草稿生成当作最终 Office 视觉验收。

## 经验与组件

经验库显示已经获得用户同意的项目经验。组件技能入口保留来源收集、待提取、参数、状态与复用记录。是否自动收录新交付项目可在组件页设置。收录来源不等于技能已验证或已启用。

项目工作链会推荐最多三条相关经验。制作 Agent 在已有阶段打卡中记录实际采用的经验编号，无需增加一次引用操作。推荐次数、报告采用和结果证据分开统计，历史经验不会自动变成本次验收通过。详细登记合同见 references/project-work-chain.md。

## 制作 Agent 接入方式

设置中的制作 Agent 接入提供界面配置和提示词接入。两种方式使用同一份客户端配置，状态分别显示配置、自检和实际 MCP 连接。

界面配置保留预览、确认写入、本机自检及验证提示词。提示词接入会根据所选客户端和当前安装位置生成命令，复制给能够操作本机文件和终端的 Agent 后，由 Agent 完成配置。生成和复制提示词本身不会写入客户端配置。

接入命令只处理本工具箱的 MCP 条目，写入前备份，保留其他服务和设置。已正确配置时跳过重复写入。配置冲突会停止；如果写入成功但自检失败，结果分别报告这两个步骤。接入不创建项目或修改执行权限。

客户端支持刷新 MCP 时，Agent 可以继续刷新并验证；无法自动刷新时仍需用户操作。口令在准备验证时新生成，有效期 10 分钟。必须由当前客户端实际调用工具完成验证，本机自检不代表 Agent 已接入。通用客户端仍需确认其配置入口，不能保证自动写入。

## 设置、规则和更新

设置按常规与权限、制作 Agent 接入、制作规则、工具与指令、软件与扩展包、插件来源和日志组织。自动批准只处理符合现有规则的新申请，拒绝或归档的申请保持原状态。制作执行开关用于受管 MCP 和 CLI 调用，PPTAgent 的 API 启用单独设置。

概况页的连接状态显示制作 Agent 的 MCP 会话。PPTAgent 的 API 连接与处理记录在左侧 Agent 接入页查看。使用统计记录经验、工具、图标和组件技能的使用次数；采用经验可随阶段打卡登记。归档不清除历史统计，模型 Token 和费用仍在 API 服务商处查看。

帮助从当前随包文件读取。安装包统一更新程序、随附说明书和内置 Skill，用户覆盖保存在管理数据中。随包原文变化后，覆盖文档会显示核对提示。比较原版、合并保存或恢复原版后，再刷新 Agent 上下文。制作指令模板也能保存用户覆盖，新建制作每次复制都会读取当前内容和目录设置。

软件升级可在版本与更新页检查、下载和安装，也可运行新版 Setup.exe。早期版本需先手动升级一次 1.21.0。自动检查默认每天一次，可关闭；下载和安装由用户发起。签名和文件校验失败会停止更新，有活动任务时等待。安装沿用原管理数据与项目位置。ZIP 导入仍只用于扩展工具包。

管理配置导出不包含完整 PPT 项目。完整项目文件保留在各自工作目录，新建准备任务可以单独导出原图和指令。分享导出物前请检查业务内容和本机路径。

## 软件版本与项目运行路径

版本与更新页显示统一的软件发行号，内置制作工具随安装包更新。独立扩展在折叠区导入与切换，具体规则见[版本与更新](VERSIONS.md)。

项目顶部会显示调用失败、等待原因和结果待确认；选择步骤可进入关联功能或查看调用详情。点开项目后可查看自动排布的运行路径，分支与汇合由步骤关系生成。选择方框查看详情，可缩放或适应宽度。大阶段打卡继续沿用，阶段内无需逐工具汇报。制作 Agent 与驻留 PPTAgent 的更新方式见[工作图说明](../references/project-work-graph.md)。
