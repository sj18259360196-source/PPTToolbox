# 学习库

学习库保存在当前管理数据目录的 `learning` 中，与程序文件分开维护。程序升级保留这个目录，但会重新比较技能的执行依赖。版本不兼容的技能不能继续沿用旧验证结论。

## 项目收录

学习库页可以开启收录新交付项目。受管 `finish` 完成交付后，会记录对应项目、交付版本和来源文件哈希。重复完成同一交付不会增加一条重复记录。

已有成品可在学习库页选择后收录。此操作只读取已登记项目，核对来源并写入学习库，不修改原 PPT 或推进原任务。项目未交付、来源变化或身份不一致时拒绝收录。

收录的项目处于待提取状态。来源中的文字和形状仍需经过选择、参数绑定及新任务验证。

## Agent 调用

先读取 `toolbox_context`，确认当前程序和管理数据目录。`toolbox_learning` 返回技能状态、待提取来源和复用记录；传入来源 `id` 可读取可选对象及来源参数。

在新项目中通过 `rebuild_skill_capture` 明确选定组件对象，绑定当前任务的文字和允许变化的样式。随后使用原有 `rebuild_skill_apply`、`rebuild_compare`、`rebuild_adopt` 和交付流程。

启用仍由 `rebuild_skill_validate` 和 `rebuild_skill_activate` 控制。同版本至少需要两个项目、三种不同输入的有效交付证据。管理页只能停用技能，没有跳过验证直接启用的入口。

## 结果范围

复用记录保留成功应用的历史结果，以及受管应用的失败原因。历史通过只对应当时观察过的输入，不代表任意尺寸、文字长度或另一台电脑也能通过。

文件完整性和自动测试不能代替真实 PowerPoint 渲染、视觉观察及编辑读回。界面中的版本不兼容和待复核必须处理后才能继续使用。不得修改哈希、直接更改数据库状态或复制旧通过结论来绕过验证。
