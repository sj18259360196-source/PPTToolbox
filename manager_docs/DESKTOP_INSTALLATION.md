# 桌面安装与 Agent 接入

## 安装

从本项目 Releases 下载并运行 `PPTToolbox-1.21.0-Setup.exe`。默认只为当前 Windows 用户安装，不需要管理员权限。安装程序提供程序目录、管理数据目录和默认 PPT 项目目录选择，并创建开始菜单入口。桌面快捷方式可选。

程序依赖 Microsoft Edge WebView2 Runtime 和 .NET Framework 4.6.2 或更高版本。安装程序会检查这两项，缺少时给出安装提示。制作和验收 PowerPoint 文件仍需本机安装 PowerPoint。安装包内含 Python 运行环境，无需用户另装 Python。

已有安装继续使用原程序位置和管理数据。升级不按旧版 location.json 的项目根目录覆盖当前设置。需要搬动目录时，从设置页进入安装与迁移。

## 在设置页接入 Agent

首次打开桌面窗口会进入设置页。选择 Codex 或 Cursor，核对客户端配置文件路径，再点击预览配置。确认写入只修改 `ppt_toolbox_manager` 条目，并在旁边备份原文件。其他服务和设置会保留。遇到同名但来源不明的条目时停止写入，由用户核对。

其他 MCP 客户端可以复制通用配置，在其 MCP 设置中添加。不同电脑必须生成各自的绝对路径配置，不能照搬开发机的路径。

接入页分别显示以下结果。

1. 客户端配置是否存在，并指向当前工具箱。
2. 本机 MCP 能否启动、列出工具，并返回与当前窗口一致的程序和数据目录。
3. 外部 Agent 是否完成一次性连接验证。

写入后，在客户端刷新 MCP 或重启客户端。点击复制验证提示词，在十分钟内发给 Agent。Agent 需要调用 `toolbox_verify_connection`，随后读取 `toolbox_context`。回到设置页点击检查配置，查看验证结果。验证口令只能使用一次；本机自检进程不能用它完成外部验证。

通过连接验证不授予项目执行权限。允许受管执行、自动批准项目等设置仍由用户选择。客户端上报的名称用于显示，不能当作可信身份认证。

## 更新与恢复

Agent 的正式入口固定为安装根目录下的 `agent_bridge.py`。在同一位置升级后，配置无需更改版本号或构建目录。旧的 portable.py MCP 入口继续可用。

安装更新前检查未决调用和项目写入锁。有未决工作时暂停更新，不强制终止。新版空闲桌面与 MCP 进程支持退出请求；旧版后台不支持时，需用户从托盘退出窗口并停止对应 MCP 服务后重试。

更新前在管理数据的 `application-updates` 中保存数据库、位置配置和被替换文件。替换失败或新运行环境导入检查失败时，回滚本次程序文件修改。断电留下 UPDATE_PENDING.json 时停止启动，保留现场供恢复处理，不静默重试。数据库备份含维护锁记录，手动恢复必须核对并释放对应维护锁，不能直接覆盖正在使用的数据库。

从 1.21.0 开始，版本与更新页可检查 GitHub Releases 并下载完整安装包，签名与文件摘要验证通过后再运行。没有网络时仍可使用已安装版本，也可以手动下载安装包。Microsoft Authenticode 证书和全量离线 WebView2 安装包尚未提供。

## 卸载

Windows 的已安装应用列表提供卸载入口。卸载前检查运行进程和未决任务。卸载只删除发行清单中的程序文件、快捷方式和卸载入口，保留全部管理数据、PPT 项目和用户自己放入的文件。

位置与产品标识会保留，便于再次安装时找回原数据。Agent 配置也保留；卸载后该连接暂不可用，重装到同一位置可恢复。无需保留接入时，可在客户端删除 `ppt_toolbox_manager` 条目。
