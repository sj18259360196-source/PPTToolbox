# 项目、成品与空间管理

项目页先读取文字登记索引，PPT 与矢量项目共用搜索、分类、排序、整理、归档及恢复。点击已登记项目名称后读取该项目的文件和工作记录，点查看存储后统计空间。成品页只显示未归档项目的成品，归档项目及其成品统一在已归档页查看。PPT 项目默认预览当前 PPT，历史文件保留在原项目内。

## 矢量项目的操作范围

矢量项目从同一个项目入口打开，详情提供运行路径、项目文件、制作记录和助手摘要。默认显示最近交付版本；没有交付时显示最新制作版本。历史版本单独保留检查、文件与交付，标题状态和下一步提示按所选版本计算。出现新候选不会改写旧交付，旧失败也不会显示为已交付。

整理项目可改名称和分类，画布、参考图、输出格式与文字模式在创建时固定。文件页可打开、定位和下载交付文件、候选文件、源文档 JSON、附带 SVG 源文件及冻结参考。归档不移动或删除文件；关闭矢量入口后已有项目仍可管理。

矢量项目保留源文件和全部版本，不提供 PPT 的交付并完结、重新开启、制作历史清理和项目导出包操作。混合批量交付或清理会跳过矢量项目并给出原因。空间管理显示实际占用。逐版返修、导出恢复与格式限制见[矢量项目使用说明](VECTOR_SPACE.md)。

## 排序与子项目

项目页初始按最近活动优先显示。选择手动顺序后，每行的排序菜单可上移、下移、移到最前或最后，切回手动排序时继续使用保存的顺序。子项目只在同一上级内排序，调整前后位置不会改变父子关系或移动文件夹。

排序框还提供最近活动优先、较早活动优先、名称正序和名称倒序。搜索和分类保留；手动调整作用于当前显示的同级条目。

## 单独与批量归档

勾选项目后使用批量归档。全选包括筛选结果中的子项目，单独勾选父项目不会连选子项目。归档只调整可见范围，文件、交付记录和历史使用统计保留。已归档页可单独或批量恢复。

未开始制作的启动申请也有复选框和归档申请按钮，目录尚未创建或已经不存在时仍可归档。恢复申请后保留原审批状态；已归档申请不会被自动审批或同路径的启动重试重新激活。正在调用或结果尚未确认时先处理原任务。

## 批量交付

本节用于 PPT 项目，矢量交付由制作 Agent 完成当前版本的检查与逐格式登记。

勾选项目后点批量交付，先检查每个项目的交付方案和要保留的 PPT，再确认执行。成功项完成后取消勾选，未完成项保留选择并显示原因。仅选启动申请时交付按钮不可用，混合选择时跳过申请并处理已登记项目。

## 交付并完结

在项目的更多菜单中选择交付并完结，核对要保留的 PPT，然后确认。

已有正式交付文件会保留原位置。选择制作目录中的候选文件时，工具会另存到本项目的 `delivery/owner-*/editable.pptx`，并记录文件校验值。用户确认与工作流验证分别记录，用户完结不会自动补写视觉验收。

完结后停止原项目的受管制作。尚未清理历史时，可以重新开启。归档只调整项目列表，与完结、清理分别管理。

## 清理制作历史

本节用于符合条件的 PPT 项目，矢量项目没有历史清理入口。

已完结项目可以从项目列表或空间管理进入清理。先查看预计释放空间和文件范围，再确认永久删除。预览十分钟后失效，文件或项目状态发生变化时需要重新检查。

可清理范围包括制作版本、试验文件、项目临时目录、工作流历史和项目调用日志，以及交付包里的制作副本。成品 PPT、交付记录、原始参考、素材、成品预览和项目状态会保留。未知目录不会自动归入清理范围。

制作中的项目、有未决调用、存在写入锁、目录含链接或文件被其他项目作为输入时，清理会被阻止。保留成品缺失或校验值改变时也会停止。

删除中断会记录已删除文件数与释放空间。再次检查后可清理剩余部分，不会把部分成功显示为全部完成。

历史一旦清理，不能恢复旧候选、渲染和原 Agent 制作流程。保留的 PPT 可以直接编辑。需要 Agent 再制作时应建立新项目。

## 空间统计与分组

占用按文件大小统计，不是运行时内存，也不是文件系统簇分配量。后台扫描结果显示统计时间，读取不完整时标明下限。扫描有数量上限，不会把未读取的内容当作零。

参考素材、成品与制作历史分别计量。全局工具缓存、界面缓存、图标库及升级备份单独展示，不分摊到某个项目。

物理嵌套的已登记子项目单独统计，汇总去重。项目分组只保存上级关系，不移动文件。系统依据路径提出分组建议，保存前需要用户选择。

## 技术记录

项目完结和清理状态保存在 `workflow/project-lifecycle.json`。原工作流状态保持原样。清理前保留成品的哈希会重新检查，删除意图先写入记录，再逐文件核对和删除。

清理后保留的交付收据可能引用已经删除的制作证据。该收据仅保留历史记录，不代表工具还能重新验证整条证据链。

## 运行路径图

项目内部显示方框与连线组成的工作图，支持分叉、汇合和路径调整。默认按阶段记录和实际调用生成；需要细分时，Agent 只填步骤类型、编号和前后关系，软件补齐名称、功能入口并自动排布。严重异常固定显示在项目顶部，收起后仍保留原始记录。图上的登记状态和工具执行状态分别标明。实际调用、经验与打卡记录可按需展开，当前 PPT 仍只展示当前版本。详情见[工作图说明](../references/project-work-graph.md)。

矢量运行路径复用同一图形布局，按冻结设置、所选制作版本和全项目当前管理分组。结构检查、各格式导出、看图检查、交付与失败来源来自保存记录。当前助手或服务状态不与历史版本连成制作因果。选择节点查看时间、结果和下一步，完整路径与文件摘要按需展开。刷新保留节点选择与缩放，图本身不执行制作或交付。
