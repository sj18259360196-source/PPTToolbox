# 来源经验库

经验库默认显示来源经验。可按编号、方法、问题和来源编号搜索，也可筛选外部导入、历史复盘和待验证建议。任务复盘与组件技能保留各自入口。

每条经验旁的次数可打开使用明细。检索、详情查看、原文查看和任务引用分别统计，具体口径见 [使用统计](USAGE_COUNTS.md)。

条目详情包括适用条件、具体方法、验证方法、限制、失败相关摘录及原文出处。失败摘录按关键词定位，建议段落仍标为待验证。原文读取核对 SHA-256，使用归档文件中的物理行号，每次最多读取 80 行。历史结果不代表当前 PPT 已经通过验收。

随包索引位于 `assets/experience/knowledge`。外部导入位于当前管理数据目录的 `experience-library/imports`，保存条目、原文字节、手册及文件摘要。升级只替换程序文件，继续读取原管理数据目录。UI 与受管工具使用同一份合并索引。

公开发行版使用空的个人经验索引，不分发作者的历史项目复盘。已有安装升级时，旧内置经验会先转存到本机外部导入目录；原有导入和任务学习记录保留。新用户可以逐步积累自己的经验。

维护人员可通过以下命令将已经审查、符合经验索引格式的快照导入独立存储。

```powershell
python -B scripts/experience_library.py import-snapshot --snapshot <已审查快照根目录> --builtin <随包索引根目录> --storage <管理数据目录>/experience-library
```

此命令接收完整索引快照，保存与随包索引不同的内容。它不自动从任意 Markdown 中提炼经验，也不执行原文里的命令。重复导入相同内容复用已有存储；来源编号冲突或文件摘要不符时返回错误。导入目录独立于程序目录，不随应用安装包分发。
