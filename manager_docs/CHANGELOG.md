# 软件更新记录

## 1.21.0

新增公开发行与软件内更新。可检查、下载、校验和安装 GitHub Releases 中的完整安装包，支持取消、重试和任务结束后安装。更新使用签名清单，保留原安装位置、设置、授权和项目。公开构建使用固定版本与哈希的独立运行环境，预览 PDF 转为 PDFium。公开安装包不含个人项目复盘，旧安装的内置经验转存到本机管理数据。

## 1.20.8

插图增加绘制后转入生图的路线。Agent 判断局部相似度低于 75% 时可申请透明背景素材，用户明确要求优先。生图请求中的判断记录自动进入默认工作图，支持同图多图标及独立裁剪回装。同步修改素材校验、启动指令和帮助，保留原生文字、图表与关系线的要求。

## 1.20.7

修复运行路径把成功调用误标为等待处理的问题。自动采集的细分节点改为显示调用已完成，无需补打卡；真实的授权等待、占用、失败和结果待确认继续显示。保留大阶段记录及 Agent 登记的步骤状态。

## 1.20.6

工作链增加十类常用步骤，软件补齐名称和功能入口。接入图标、图形工具的项目调用记录，失败与结果待确认单独显示。项目顶部保留未处理异常、等待原因及下一步建议，采集失败时提示最近可用记录。修复失败后仍显示进行中的问题。异常收起保留记录，不改变任务结果和权限。帮助及 Agent 接入说明同步更新。

## 1.20.5

统一软件与内置组件的发行号，由 release.json 提供版本来源。软件更新、扩展工具包切换和诊断信息分别显示，增加启动时的软件版本记录与扩展兼容范围检查。保留历史项目版本、用户指令和权限。

项目运行路径改为紧凑的横向流程图，长流程自动换行，密集分支分组展开，折线绕开方框并以颜色区分路径。支持分叉、汇合、缩放和步骤详情。默认使用大阶段记录，制作 Agent 可随打卡提交增量步骤，驻留 PPTAgent 可在所选项目内更新展示图。状态来源单独标明，图的更新不推进制作阶段或交付审批。

## 1.20.4

同步帮助、概况制作提示词、设置和使用统计。制作 Agent 的 MCP 与驻留 PPTAgent 的 Responses API 分别说明，权限、打卡和经验采用按当前实现更新。当前手册补齐项目排序、批量交付、启动申请归档与恢复，旧版接入结果标为历史记录。保留用户保存的指令，随包原文变化时提示核对。

## 1.20.3

未登记的启动申请增加归档入口，支持批量归档和恢复。项目默认采用手动顺序，可上移、下移、移到最前或最后，并提供名称与活动时间排序。归档项目及其成品只出现在已归档页，成品页显示未归档项目的成品。

## 历史组件版本 1.4.1

随包核心v1.3.1；注册统一区域和预审工具，受管命令新增workflow.preview。更新启动时同步builtin版本，保留用户覆盖并记录需核对差异。未改变数据库格式和HTTP/MCP协议。

## 历史管理器版本

## 1.4.0

首次本地管理软件版。独立于随包ppt-reference-rebuild 1.3.0核心。

新增管理概览、Skill版本/入口启停、86项工具与工作流指令目录、用户覆盖编辑/差异/恢复、自定义指令、离线包预检/导入/切换、Codex/MCP配置与市场写入预览、设置和日志。

新增只读MCP发现服务、受管CLI、Windows启动器、SQLite修订状态和本地HTTP认证。保留旧制作核心代码与测试。

没有PPT制作画布或设计稿上传功能。没有在线更新源、exe发行、插件市场发布或真实跨模型稳定性认证。
