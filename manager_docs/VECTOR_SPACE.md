# 矢量项目使用说明

本文对应 1.30.2。矢量空间用于独立矢量项目，已有项目与 PPT 项目共用项目页。PPT 制作中的位图矢量化另见[位图矢量化](../references/bitmap-vectorization.md)。

## 开始一个项目

1. 在设置的实验室中开启矢量空间。受管执行和项目授权仍按当前设置检查。
2. 打开左侧矢量空间，选择本次输出格式，查看完整提示词。不可用的格式无法勾选，PNG 预览自动附带。
3. 点击复制提示词并新建编号，连同参考图和要求发给已接入的制作 Agent。每次复制签发独立的 VEC 编号，草稿预览不代表已经签发。
4. 制作 Agent 读取该编号，确定项目名称、画布和附件，再建立项目。画布、参考文件、输出格式及文字模式随项目固定；需要改变这些设置时新建项目。
5. Agent 提交结构化几何文档，由工具箱导出文件。之后查看真实 PNG，登记具体检查发现，再按该版本交付。调用方式见[矢量制作合同](../references/vector-space.md)。

关闭矢量入口后不能签发新请求或提交新版本。已有项目仍可在项目页查看、整理、打开文件、下载、归档和恢复；可执行操作以当前权限和工作进程状态为准。

## 在统一项目页管理

从项目页按名称、编号或路径搜索，按分类筛选，并使用手动顺序或名称、活动时间排序。点击项目名称进入同一套项目详情，顶部显示项目名称和整理、刷新、文件夹等操作。矢量空间只用于准备新制作，已有项目统一从项目页进入。

矢量与 PPT 项目可一起归档、恢复。归档不移动或删除文件。PPT 的批量交付、交付并完结、制作历史清理不适用于矢量项目；混合批量交付或清理会跳过矢量项目并显示原因。矢量项目保留源文档、所有版本与检查、交付记录，空间管理用于查看占用。

## 选择制作版本

已有交付时默认打开最近一次交付对应的版本，否则打开最新制作版本。版本下拉框可查看历史版本；如果还有更新的制作版本，上方会提示其状态并提供查看入口。刷新保留手动选择的版本。

标题区、下一步提示和制作记录摘要按所选版本显示。历史失败仍显示失败，历史拒绝仍显示需要修改；另一版已交付不会替它改成成功。原始 JSON 保留底层执行状态，简短摘要还会结合该版本的检查与交付记录。例如已交付候选的原始执行状态可能仍为 `awaiting_review`，其交付结果由对应交付记录确认。

| 显示状态 | 接下来查看什么 |
| --- | --- |
| 正在导出 | 等待工作进程结束，再核对结果 |
| 执行失败、已取消或运行超时 | 查看该版本的结构检查、失败来源和调用记录 |
| 等待检查 | 查看此版本实际 PNG，由制作 Agent 登记发现 |
| 需要修改 | 按检查发现提交新版本，重新看图 |
| 已记录检查 | 已有认可记录，尚需核对格式并登记交付 |
| 部分交付 | 查看清单中不支持或失败的格式，保留缺项说明 |
| 已交付 | 打开此版本交付文件，检查实际成品 |
| 文件待核对 | 查看缺失、变化或不可读取的文件；已有交付保留为历史记录 |

需要返修时，让制作 Agent 在同一项目提交新版本。每版独立检查和交付，旧交付及其检查记录保持固定。导出完成与 Agent 看图声明各有记录，用户认可与目标编辑器实测仍需另行确认。

## 四个项目页签

| 页签 | 可以查看和操作的内容 |
| --- | --- |
| 运行路径 | 签发与冻结设置、所选版本制作记录、全项目当前服务与管理三组节点 |
| 项目文件 | 交付文件、候选文件、矢量文档与源文件、冻结参考文件，支持打开、定位文件夹和下载 |
| 制作记录 | 此版本的原始候选 JSON、检查发现、交付与活动记录 |
| 助手摘要 | 全项目当前摘要和管理备注、固定制作设置，以及打开管理助手的入口 |

运行路径按真实记录显示文档提交、结构检查、各格式导出、看图检查、交付和失败来源。选择节点查看时间、结果、关系依据与下一步，可跳到关联文件、制作记录、预览或助手。完整路径、文件摘要和关系依据收在来源折叠区。图支持缩放和适应宽度，刷新保留已选节点与缩放。

全项目当前服务和助手节点单独列出，不代表所选历史版本当时的状态。尚未发生、未知、失败和受阻都有各自状态，节点连线只表达已经记录的关系。刷新和打开节点不会继续制作。

## 导出中断时

先查看恢复说明和进程状态。原进程仍运行或身份无法确认时，恢复操作不可用。原进程已退出且保存回执、源文档和输出可核对时，可核对并恢复结果；保存的是失败结果时仍登记为失败。

保存结果不完整或未通过核对时，界面可能提供标记本次导出中断，确认后保留原日志与输出，再由制作 Agent 提交新版本。恢复不会重跑编译、自动看图或补写交付。PPT 正在占用受管服务或 Office 写入锁时，矢量制作等待该任务释放资源。

## 输出格式与编辑范围

| 格式 | 当前范围 |
| --- | --- |
| SVG | 保留矢量对象和文字。文字依赖接收电脑的字体，不自动嵌入字体或转曲 |
| PNG | 必须查看的栅格预览，不能据此认定其他格式在目标编辑器中正常 |
| Illustrator 兼容 SVG | 输出 `document.illustrator.svg`，原生 AI 导出尚未实现 |
| EPS | 仅支持不透明纯色路径，不支持文字对象、渐变和透明效果 |
| PSD | 顶层对象或分组导出为像素图层，文字与形状已栅格化；同时保留 SVG 源文件 |
| PDF | 取决于当前运行时能力，不支持文字对象、渐变和组合透明度。标准公开运行时不内置其转换依赖 |
| CDR | 导出尚未实现 |

以界面实际能力和逐格式结果为准。不支持或生成失败的格式仍保留在请求和交付清单中，不能删掉缺项或改扩展名冒充完整交付。SVG、EPS、PDF 的结构检查以及 PSD 图层生成，不代表 Adobe、CorelDRAW 或其他目标编辑器的打开与编辑验收。

## 管理助手的范围

从助手摘要打开管理助手后，项目选项沿用统一目录，任务限定在所选项目。助手可读取矢量记录、核对已登记文件、保存管理备注、整理摘要和准备交接材料。备注与摘要单独保存，不改写源文档、候选状态或交付。

矢量项目不提供 PPT 执行、Office 写入、场景预检、阶段打卡、采用候选和助手改写工作图。运行路径由保存的矢量记录生成。摘要过期、停用、未配置和处理失败按实际状态显示，旧摘要不会变成新的制作结果。模型接收范围、调用配额和配置方法见[PPTAgent 管理](PPTAGENT.md)。
